# 租赁追踪系统 (Rental Tracking System)

一个简洁高效的房源租赁管理与收支追踪系统。

## 📋 系统信息

- **名称：** 租賃追蹤 (Rental Tracking)
- **版本：** 1.0
- **作者：** CHRIS🇹🇭
- **版权：** Copyright © 2026 Notee.vip
- **技术栈：** React + Vite + Tailwind CSS

## ✨ 主要功能

### 项目管理
- ✅ 创建多个租赁项目
- ✅ 项目编辑（名称、描述、密码、可见性）
- ✅ 项目密码保护（锁定/解锁机制）
- ✅ 项目显示/隐藏控制
- ✅ 项目统计数据展示
- ✅ 项目开支管理（独立于房源的开支类别）

### 房源管理
- ✅ 添加/编辑/删除房源
- ✅ 房源状态管理（出租中/新合同/空置中）
- ✅ 租金设置（泰铢 ฿）
- ✅ 租客信息管理（姓名、人数、租期）
- ✅ 3列布局显示（房源编号 | 租金 | 状态）

### 收支追踪
- ✅ 房源收支记录
- ✅ 项目开支记录（物业费、维修费等）
- ✅ 按年份/月份查看统计
- ✅ 收入/支出/净利润自动计算
- ✅ 缴租率统计（已缴租/应缴租 × 100%）

### 权限管理
- ✅ 管理员系统（密码：notee.vip.2026）
- ✅ 项目级密码保护
- ✅ 访客只读模式
- ✅ 管理员自动解锁所有项目

## 🎯 核心特性

### 1. 双层密码保护
- **系统管理密码：** 控制所有管理功能（notee.vip.2026）
- **项目密码：** 单独保护每个项目
- **锁定机制：** 有密码的项目显示🔒图标，需解锁后访问
- **管理员特权：** 管理员自动解锁所有项目

### 2. 智能统计
- **缴租率计算：** (已缴租房源数 / 应缴租房源数) × 100%
- **应缴租房源：** 包括"出租中"和"新合同"状态
- **自动汇总：** 房源收支 + 项目开支 = 总收支
- **多维度展示：** 按年份/月份查看数据

### 3. 灵活的房源状态
- **出租中：** 租客正常居住，需缴租
- **新合同：** 已签合同但未入住，需缴租
- **空置中：** 无租客，不计入缴租率

### 4. 项目开支管理
- **独立类别：** 物业费、维修费、税费等
- **紫色主题：** 与房源（绿色）区分
- **统一统计：** 与房源收支一起汇总

### 5. 灵活的数据管理
- 导出数据为 JSON
- 导入数据恢复
- API 版本：服务器存储，跨设备访问

## 📊 数据存储

### 当前方案：localStorage（本地版本）

**优点：**
- ✅ 无需服务器和数据库
- ✅ 数据即时保存
- ✅ 离线可用
- ✅ 部署简单

**注意事项：**
- ⚠️ 数据存储在浏览器本地
- ⚠️ 不同设备数据不同步
- ⚠️ 清除浏览器数据会丢失
- ⚠️ 建议定期导出备份

### API 版本（服务器存储）

如需跨设备访问和多人协作，可使用 API 版本：
- ✅ 数据存储在服务器
- ✅ 跨设备访问
- ✅ 多人协作
- ✅ 自动备份

详细说明请查看项目内的 `docs/` 目录（本地文档，不同步到 GitHub）

## 📖 使用说明

### 管理员登录

1. 点击右上角"🔒 系统管理"按钮
2. 输入密码：`notee.vip.2026`
3. 登录后按钮变为"🔓 退出管理"
4. 所有管理按钮显示，所有项目自动解锁

### 创建和编辑项目

1. 登录管理员账号
2. 点击"创建新项目"按钮
3. 填写项目信息（名称、描述）
4. 可选：设置项目访问密码
5. 可选：设置为隐藏（非管理员看不到）
6. 编辑项目：点击项目卡片右上角⚙️按钮

### 项目密码保护

**设置密码：**
- 在项目编辑对话框中输入密码
- 有密码的项目显示🔒图标

**访问有密码的项目：**
- 普通用户：点击"输入密码解锁"按钮
- 管理员：自动解锁，无需输入密码

### 管理房源

1. 进入项目详情页
2. 点击"+ 房源"添加房源
3. 填写房源编号和租金（泰铢 ฿）
4. 设置房源状态：
   - **出租中：** 租客正常居住
   - **新合同：** 已签合同待入住
   - **空置中：** 无租客
5. 管理租客信息（姓名、人数、租期）

### 项目开支管理

1. 在房源列表上方找到"项目开支"卡片
2. 点击"➕ 项目"添加开支类别
3. 填写类别名称（如：物业管理费）
4. 点击类别查看详情
5. 添加收支记录

### 记录收支

1. 选择年份和月份
2. 在房源或项目开支卡片中点击"添加记录"
3. 填写收入、支出和备注
4. 系统自动计算统计数据
5. 查看缴租率、总收入、总支出、净收益

### 数据备份

1. 定期使用"导出数据"功能
2. 保存 JSON 文件到安全位置
3. 需要时使用"导入数据"恢复
