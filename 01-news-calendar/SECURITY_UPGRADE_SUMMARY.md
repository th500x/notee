## 🚀 部署指南

### 1. 更新代码

```bash
# 拉取最新代码
git pull origin main

# 安装依赖（如果是首次部署）
cd 01-news-calendar/backend
npm install
```

### 2. 配置环境变量

```bash
# Windows PowerShell
$env:NODE_ENV="production"

# Linux/Mac
export NODE_ENV=production

# 注意：PORT不需要设置，代码中已默认为3002
```

### 3. 重启服务

```bash
# 使用PM2
pm2 restart news-calendar-backend

# 或直接运行
npm start
```

### 4. 验证部署

```bash
# 检查健康状态
curl http://localhost:3002/api/health

# 检查安全头部
curl -I http://localhost:3002/api/health

# 测试限流
# 快速发送多个请求，验证限流是否生效
```
