# 终局 · 飞升之后

> **定位**：境界到顶之后 **游戏还没结束**——滞留真仙、刷劫、遗蜕经济、剧情交卷与沙盒续玩如何分工。  
> **前置**：进阶《流派养成》渡劫；《世界互动》异闻；《流派顶配》分神与验收。  
> **态度**：交太一秘典对话 = 该档 **剧情结束**；不交则可一直沙盒。两者都是合法终局。

---

## 0. 两条「终局」别混

| 类型 | 含义 | 你是否还能玩 |
|---|---|---|
| **战力终局** | 在世真仙、满配大哥、灭门/九劫验收 | ✅ 继续 |
| **剧情终局** | 持太一秘典入小乾坤界归寂之地与付辟空对话 | ❌ 该档剧情向结束（想续玩勿交） |

另有社区整理的「终局事件」解锁条件列表（征伐门派数、飞升人数、滞留劫次数、天数、异闻等）——用于打开终局对话资格，**不等于**必须马上交卷。

## 1. 从元神到在世真仙

### 1.1 飞升劫（首次）

元神修满 → 迎飞升劫 → 成功后境界变为 **在世仙人/在世真仙**（文案以客户端为准）。  

渡劫方法仍是进阶两路：

| 路线 | 适用 |
|---|---|
| 肉身渡劫 | 稳；堆玄甲、秘典、龟壳、真罡、灵石/晶；可不带输出法宝 |
| 法宝渡劫 | 快；高威力法宝 + 幽剑/虚极/为剑等；防反噬抽干 |

场地：克制劫云属性的约 13×13 区；战斗堂加成；天气与地面属性影响劫云灵气。

### 1.2 滞留期机制（多源交叉）

- 成功后 **滞留人间**，进入读秒周期，常见讨论为约 **5 天** 一劫（可服延长类丹药拉长间隔）。  
- 人物在指定地点打坐抗劫到来时，读秒可能暂停（机制文口径）。  
- **天劫次数无上限** → 终局核心循环之一。  
- 可查看劫云属性，用克制地板/建筑/天气削弱。

### 1.3 滞留期你在刷什么

| 循环 | 收益 |
|---|---|
| 反复渡劫成功 | **法宝洗练**：按比例抬法宝威力，可无限叠（《极品宝物》） |
| 飞升劫成功 | **参悟**；大哥工具人无限渡劫可刷参悟点（进阶已述） |
| 攒分神 | 部分流程用真仙渡劫代替造化神丹窗口（见《流派顶配》） |
| 道行劫等 | 亦可提供分神等收益（进阶渡劫章） |

**法宝选择印象**：御器流偏剑丸；一剑流偏星髓针——按你流派输出模组选，再靠洗练拉满。

## 2. 择地飞升与仙人遗蜕

### 2.1 择地飞升

- 滞留期间可随时 **择地飞升**。  
- 门派死亡数 +1（机制文）；角色离开编制，留下 **仙人遗蜕**。  
- 用途：需要遗蜕聚灵/香火/遗骨时主动飞升；需要继续洗练法宝则 **先别飞**，留在滞留刷劫。

### 2.2 遗蜕三大作用（社区归纳）

| 作用 | 说明 |
|---|---|
| **聚灵** | 聚灵约 50、范围约 9，属顶级大范围聚灵物；五行随飞升者功法 |
| **遗骨** | 拆除遗蜕得 **仙人遗骨**；服用约 **−25 道行**，加速学技能 |
| **香火祭祀** | 食物+灵晶祭拜攒香火 → 祈求祖师显灵 |

遗蜕可大范围调节地块五行——规划时当「永久风水/聚灵建筑」用，勿随手拆。

### 2.3 祖师显灵（香火兑换）

不同功法飞升，显灵种类与权重不同（完整表以游戏内为准）。功能印象：

| 显灵 | 效果印象 |
|---|---|
| 祖师除魔 | 下凡诛外魔 |
| 祖师传道 | 宣讲；问道者大量参悟，甚至降道行相关收益 |
| 祖师开光 | 提升器物品阶（约 1～4 阶讨论） |
| 祖师淬体 | 抬五维、治伤、重铸躯体 |
| 祖师庇佑 | 仙家气息、驱不良天气 |
| 祖师灌顶 | 对某人大量参悟 |
| 祖师赐物 | 珍贵道具 |

终局门派常设「祖师陵园区」：集中祭拜、安全、靠近需要聚灵的田/结丹点。

## 3. 小乾坤界与剧情交卷

### 3.1 小乾坤界（双重身份）

- 建筑/空间：储物、保鲜等实用功能（实况与社区）；亦是剧情场景。  
- 解锁与太一遗迹、**太一秘典** 等相关（见《世界互动》）。  
- **归寂之地** 对话付辟空 = 剧情结局入口。

### 3.2 交卷前检查清单

来自异闻章 + 终局条件文交叉（以你局内解锁为准）：

- [ ] 神秘身影、灭门之谜等关键异闻完成  
- [ ] 金匣残卷等道具到手（565 天窗口）  
- [ ] 太一秘典在库  
- [ ] （若追成就）社区提到的征伐数、飞升人数、滞留劫次数、天数、千古一帝等  

**重要**：没准备好续玩档就别点结局对话；需要成就可 **另开周目** 或复制存档再交。

### 3.3 交卷之后

剧情向结束；部分版本有续作画饼动画。沙盒内容以你是否保留存档分支为准。

## 4. 飞升之后的沙盒日程（推荐）

把「真仙之后」当成新阶段，而不是尾声：

### 4.1 战力线

1. 定大哥滞留刷劫 → 法宝洗练到满意。  
2. 工具人飞升 → 铺遗蜕聚灵网与香火。  
3. 遗骨减道行 → 加速下一代技能。  
4. 对照《流派顶配》补寄托满配。  

### 4.2 门派线

1. 仙家洞天是否要冲（声望风险）。  
2. 代理点与历练自动化。  
3. 丹宝产线圣品化（《极品宝物》）。  

### 4.3 剧情线（可选）

1. 异闻收尾与金匣。  
2. 存档复制 → 一支交卷、一支养老。  

### 4.4 天道 / 九劫线

天道异动与九劫是 **开局法则**，不是飞升后才解锁；但飞升后养成才够格认真打九劫验收。未开九劫的档，飞升后以「满配收藏与遗蜕经济」为主也完全成立。

## 5. 常见误区

| 误区 | 澄清 |
|---|---|
| 飞升了就要马上择地飞升 | 滞留刷劫往往更值钱 |
| 遗蜕只是剧情摆设 | 聚灵 + 香火 + 遗骨三件套 |
| 结局=删档 | 交卷前可分支存档 |
| 真仙模式 = 飞升之后 | 「真仙模式/仙难度」是开局难度选项，与滞留真仙不是同一概念 |
| 飞升后异闻没用 | 剧情党仍要在交卷前做完；战力党可跳过 |
