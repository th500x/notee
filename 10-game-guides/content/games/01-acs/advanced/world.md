# 进阶 · 世界互动

> **定位**：门派之外的地图、门派、异闻与代理如何服务于成长与结局。  
> **前置**：基础《玩法与机制》中的历练/驻扎概念。  
> **态度**：异闻 **无强制战力奖励**；剧情党做全线，养老党可跳过（社区明确说过）。做剧情请多存档。

## 1. 历练 · 驻扎 · 进地图

### 1.1 三者区别

| 行为 | 目的 | 通行权 |
|---|---|---|
| 历练 | 周期掉落；高机缘+匹配功法吃高级产 | 通常不需要 |
| 驻扎 | 主要为了 **进入**；驻扎产出一般 | 通常不需要 |
| 进入地图 | 场景唯一物、对话、观摩、搜刮 | 属地进入通常要 |

进图耗时 **不推进** 门派主世界时间（长期社区共识）——可安心搜刮。

### 1.2 效率技巧

- 佩戴神视/神行类符加快周边解锁。  
- 归来点分放四边并附娱乐。  
- 门规可改默认历练选项。  
- 蜀山线刷解锁玉泉洞等地；地母灵液等关键物资优先。  
- 门派属地：历练拿灵根可能被拦；**进图拿** 往往可行。  
- 门派地图：可吃饭观摩；乱偷高价值易被打死。昆仑炼法坛务必早观摩。

### 1.3 历练员编制

资料长文常给五行历练号（如金七杀、水太和、木轮回、火三阳、土偷天等）——金丹期往往够用。机缘是高级掉落的关键门槛。

## 2. 门派外交与破心防

### 2.1 外交小人

优先 **魅力 + 处世** 高（千小茜一类轮回者）。地位尽量与对话对象对等（长老对长老问得快）。

### 2.2 好感结构

| 节点 | 约略 | 解锁 |
|---|---|---|
| 心防线 | 常约 60 | 问行踪、擅长、他人执念/弱点 |
| 破心防后 | — | 可继续聊到满、问隐秘 |
| 满好感 | ~100 | 精通之法送金色野法；剧情关键隐秘 |

### 2.3 破心防标准流程（交叉多帖）

1. **用 A 的喜好去聊 B**：先问喜好厌恶 → 拿 A 的喜好点与 B 讨论 → 快速到心防线。  
2. 在心防线 **问 B 对目标的执念/弱点**（讨论→选人物→问号）。未到心防线乱问易掉好感。  
3. 找到目标：先用「聊别人」堆到心防线 → 再讨论其执念 → **破防**。  
4. 破防后继续聊别人刷满；邀请回山门再馈赠心仪物（减少离图闪退风险）。  
5. 馈赠：装备礼物 → 一件件给，常换回功法/携带物。重要对象（如武当鸭多心仪）建议存档。

### 2.4 性格特例

| 性格 | 处理 |
|---|---|
| 天真 | 心防极弱或近无 |
| 冷漠 | 灵宠撒娇（狗/狐等养成）或灵魂拷问等强制手段 |
| 贪婪 | 送礼概率或问执着即可（测试口径不一，以实机为准） |

### 2.5 天下界面送礼

掌门喜好不一定「高档」——棉花、锄头也常见。人情用于部分交易；门派好感影响历练收益。种子帖（如万仙）常附喜好表，可对照。

### 2.6 「火烧大能」等灰产

社区用于拿圣品符、拷问等；易误杀剧情 NPC。剧情党慎用；非剧情党也建议晕而非死。本站不鼓励依赖恶性 BUG。

## 3. 异闻主线（时间轴）

### 3.1 总序（BWIKI）

1. **约第 21 天**：重回太一 → 神秘身影（月清愁）线开启。  
2. 各门派调查线索，推导 **灭门之谜** 角色。  
3. **金匣**：约 **285 / 447 / 565** 天三次（交叉文；以你局内事件为准）。  
4. **第 565 天第三次金匣**：若已完成神秘身影 **且** 灭门之谜 → 出现第四选项 → **金匣残卷**。错过则主线结局向受阻。  
5. 解完系列异闻并满足其他条件 → 持 **太一秘典** 入小乾坤界归寂之地与付辟空对话 → **结档结局**（想续玩勿交）。

### 3.2 异闻解锁条件摘要（BWIKI）

| 异闻 | 条件印象 |
|---|---|
| 神秘身影 | 1 动 1 参 3 证 |
| 灭门之谜 | 8 动 8 参 8 证 |
| 上古秘闻 | 1 动 8 参 1 证 |
| 往日秘辛 | 2 动 1 参 1 证；动含金船残卷+仙魔之战卷一等，参殷莲，证太一秘典 |
| 外传：上古信息 | 1 动 1 参 1 证（任意）；与殷莲灵魂讨论等相关 |
| 千古一帝 | 自动 |

具体「动参证」条目以异闻 UI + Wiki 人物表为准；社区帖有完整组合，实操时打开 Wiki《异闻资料》对照。

### 3.3 关键地点与道具

| 物品/点 | 作用 |
|---|---|
| 太一遗迹 / 太一秘典 | 主线核心；开局线务必拿 |
| 上古卷轴 | 多由特定 NPC 携带（应扬、霍离、殷莲等） |
| 金匣残卷 | 565 天第四选项；前置两异闻 |
| 玉晶潭 | 金匣相关地图，需提前解锁（限时事件文警告） |
| 岭南代理中级事件 | 限时神修功法等，错过可能永无（交叉文） |

### 3.4 关键门派人物（BWIKI《异闻资料》导航表）

| 门派 | 关键人物 | 关联抓手 |
|---|---|---|
| 栖霞洞天 | 月清愁、宁宵、甘鸣、林思源 | 神秘身影动/参/证 |
| 青莲剑宗 | 应扬 | 随身 **上古卷轴十五** |
| 紫霄宗 | 申屠息、辛旗、秦杰 | 灭门之谜动/参/证 |
| 丹霞洞天 | 苏冰峦、谢思、霍离 | 灭门；霍离带 **上古卷轴一、七** |
| 合欢宗 | 殷莲、清羽兰 | 灭门/上古核心；殷莲灵魂线 → **外传上古信息**（太一秘典解封相关） |

**殷莲灵魂拷问 / 外传**：敏感操作，务必先存档；社区视作解秘典关键步骤之一。

### 3.5 结局提醒

- 交太一秘典对话 = **该档剧情结束**。  
- 另有「真仙多次渡劫开小乾坤」等官方/社区提到的旁路条件——以你版本公告为准。  
- 剧情本身几乎不给战力；为剧情服务的是 **外交能力与时间管理**。

## 4. 代理点与声望

- 影响力用于入驻/管理代理；信仰可供神修与参悟。  
- 岭南等代理有 **限时事件**（功法），升到中级后留意提示。  
- 声望双刃剑：高则强敌；大凶山门等手段见《门派发展》。

---

## 5. 限时事件意识（防永久错过）

| 类型 | 风险 |
|---|---|
| 金匣三次 | 地图未解锁、选错选项 |
| 岭南失传功法等 | 过期永无 |
| 565 前未解两异闻 | 无金匣残卷选项 |
| 剧情 NPC 被杀 | 线索不全 |

策略：大事件前存档；提前解锁相关地图；非必要不杀蓝名/剧情名。

## 6. 分支：天道异动

- 种子可恒定部分开局布局；铅笔输入/导入导出见基础《种子地图》。  
- 高频种子：三界无敌 043/042、弑仙等。  
- 词条：太玄/太易常被评纯负面；地母石碑较可控；和谐之世偏秘籍剧情；化妖/祭妖玩法向。  
- 异动不取消外交/异闻，但会改变资源与事件节奏——开九劫前建议先会练大哥（社区建议）。
