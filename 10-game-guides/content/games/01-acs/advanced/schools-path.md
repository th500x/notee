## 1. 仙修核心节点：结丹

### 1.1 结丹在做什么

结丹 = 把角色灵气转化为 **金丹灵气**；金丹灵气决定品级，并长期影响灵气上限与后续瓶颈难度。  
相关乘区（BWIKI《结丹》）：时节、阴阳、天气、地块灵气、功法匹配、心境、五行匹配、人物灵气值等。

**机制要点（Wiki 测算口径）**

- 结丹时每帧消耗灵气相对固定，每帧积累的金丹灵气浮动；测算约 **每游戏小时消耗 750 灵气**。  
- 初始结丹速度 ≈ `(基础30 + 地块灵气/50) × 功法匹配 × 机缘 × 心境 × 阴阳 × 天气 × 季节 × 五行`。  
- **1.0 正式版衰减**：金丹灵气过一品线后，真实速度 ≈ `初始速度 ÷ (金丹灵气/100000)`——越往后越慢，极限超品更吃准备。

### 1.2 品级门槛（BWIKI 金丹品相标准线）

| 品级 | 金丹灵气 |
|---|---|
| 九～五品 | 0 / 6,000 / 13,000 / 21,000 / 30,000 |
| 四～二品 | 40,000 / 55,000 / 85,000 |
| **一品** | **145,000** |
| 超品 | 300,000 |

> 回坑目标：普通难度稳定 **一品**；极限党再追超品/更高面板。

### 1.3 外因：时间 · 天气 · 地点

**季节五行**：春木、夏火、秋金、冬水；相生季节结丹更顺。每季约第 10、24 日为季节高峰节点（BWIKI）。  

**阴阳（昼夜）**：

| 功法倾向 | 更合适时段 |
|---|---|
| 火、木（偏阳） | 白天 |
| 金、水（偏阴） | 夜间 |
| 土 / 无属性 | 傍晚或凌晨阴阳较平衡段 |
| 两仪阴阳双丹 | 勿当无属性：阳丹按火条件、阴丹按水条件；春/秋 10–12 日等综合窗口常见推荐 |

**天气**：仙界气息对全属性友好；五行灵弥漫、尘暴/焚风/雷暴等可用术法召唤但会牵动阴阳——选天气时同时看阴阳是否被坑。火修驱云求晴、木修慎盲目求雨等，属实操常识。

**地点**：

1. 先按功法选好地块五行（观星台），再摆聚灵，否则五行永远拉不满。  
2. 聚灵阵拉高地块灵气（面板 5+ 只是起点，极限要远高于此）。  
3. 摆阵原则与基础篇一致：大范围外圈、小范围内圈；可配合炼法坛作中心聚灵。  
4. 结丹前可做爆灵抬峰值（见《门派发展》）。

### 1.4 内因：匹配 · 心境 · 灵气池

**功法匹配**：尽量满足五维需求；BWIKI 称 **130%+** 后边际变小。缺维可用技能/丹药补。  

**匹配度公式（BWIKI《结丹》）**

```
匹配度 ≈ Max(0.5, 1 − 0.2×缺维总和 + 0.04×超维总和)
```

- 每缺 1 点建议值 ≈ **−20%**；每超 1 点 ≈ **+4%**  
- 机缘另有独立结丹乘区（约 `0.8 + 0.075×机缘`）

**主流无上大法 · 五维匹配需求（BWIKI《功法匹配度列表》）**

**特殊轮回者速查（BWIKI，开局五维）**：子非鱼 5/5/3/**9**/**8**；扬大 2/**9**/2/4/2；孙亚龙 6/**8**/6/5/5；豆豆 5/2/5/4/**8**；陆夫人 6/5/5/**7**/6；飞羽仙狂 5/5/**8**/5/6（潜力约 5.84）。完整表见 Wiki《特殊轮回者》。选人对齐上表匹配需求，再靠后天技能补维。

**机缘**：独立乘区；过低会明显拖累金丹灵气。  
**心境**：结丹过程会掉心境。BWIKI：宜把心境**基础值抬到 100+**，过程中仍尽量落在无暇档。  

| 心境数值 | 层级 | 加成系数（Wiki） |
|---|---|---|
| 0～39 | 崩溃 | 0.3 |
| 40～49 | 不稳 | 0.6 |
| 50～69 | 中正 | 1.0 |
| 70～79 | 圆润 | 1.2 |
| 80～94 | 通明 | 1.5 |
| **95～** | **无暇** | **2.0** |

常见抬基础：香囊、圣牌类、心境功法（真武录等）、清心丹/草、天人合一等天赋。  
**机缘**（Wiki）：约 `0.8 + 0.075×机缘`；机缘偏低会明显拖累金丹灵气。  

**抬人物灵气上限（结丹前优先）**：

1. 气感等级（根本灵气公式核心之一）  
2. 学各类「加灵气上限/根本灵气」技能（含跨属性；相克会堆道行，后续可用窃道果等处理）  
3. 天材地宝：地母灵液、赤参、紫芝、紫毁丹等（注意耐药；邪脉血泉永久伤心境基础，神修禁吃）  
4. 炼精化气（憋丹）：极限向，耗时长，非一周目必做  

> 养成到顶后的 **灵气上限 / 法宝威力 / 御器** 等实战面板数，见终局《流派顶配》。  

### 1.5 结丹操作清单（执行版）

1. 修炼堂划区、气感与关键技能到位。  
2. 聚灵阵 + 五行环境调到目标功法相生。  
3. 心境装备/符咒预留（天通洞神符等），清心丹随身。  
4. 选季节高峰日 + 正确昼夜窗口 + 天气术。  
5. 可选：结丹前短时吃药抬匹配/心境（筑基丹、聚灵丹等视情况）。  
6. 存档 → 开始突破 → 盯心境与灵气，必要时中断重来。

两仪结丹（Wiki《玄天真武两仪妙道》口径）：**阳丹按火、阴丹按水**，勿当无属性。  
常见综合窗：春/秋 **10–12 日**；白天段放火向天气，夜间段放水向天气（放不出金/木灵弥漫时，用对应火/水术代替）。

## 2. 仙修中后期：参悟、藏经、法宝与本命符

### 2.1 参悟经济学

- 学技能加道行 → 后续技能更贵。  
- 优先：灵气、气感、心境、历练、关键神通/护体；战力虚华后置。  
- 藏经阁：收录降耗、容量与道行相关；相生属性互学更省。  
- 金丹期以上收徒：亲传大幅减耗。  
- 后期参悟：代理点信仰、道统丹、渡劫刷参悟（飞升劫成功可刷）等。

### 2.2 符修职能拆分（进阶）

| 号 | 本命符思路（社区常见） | 用途 |
|---|---|---|
| 战斗大哥 | 伪玄甲 + 真玄甲/利剑/灵剑/圣咒等组合（伪符过渡，真符压轴） | 守家与攻坚 |
| 探图 | 分影、神行、神视 | 解锁地图、驻扎进图 |
| 炼丹 | 万化承丹（伪×多 + 真×1） | 丹品质 |

符修可自重生做寄托套（分神压力相对两仪友好）；极限输出多数讨论仍逊满配纯阳。

### 2.3 七杀 → 过渡大哥

成型快、少抠阴阳；可学两仪「为剑」等补起手。适合先建立灭门能力，再决定是否转两仪上限。大衍神算等获取线属可选加速，非唯一路径。

### 2.4 两仪上限与道行

- 双元神/多法宝是强度来源。  
- 纯阳常需精算阴阳道行；太阳分支另有侧重（争议长期存在，本站不判「唯一最强」）。  
- 分神要留给压道行/寄托技能；天道异动环境下「大哥自己寄托秘宝」不一定最优——工具人寄托更灵活（社区共识）。

## 3. 寄托体系（仙修上限核心）

### 3.1 原理（一句话）

元神期用 **分神** 把技能「冻」进装备；穿戴者获得技能效果。身体与灵魂计数在夺舍/重生流里要分开理解。

### 3.2 分神从哪来

常见来源（机制文归纳）：分神之术（主来源，耗寿、伤元气，常配造化神丹窗口连放）、东木分神书、虚空谒神法、玉清五行元神择一、古修三尸分神、天道本源炼化、龙/凤/阴阳真灵丹、盘古元神丹、道行劫/飞升劫各 +1 等。  
两仪因双元神，**攒分神效率高**，故寄托流后期常落两仪。

### 3.3 两条主流流派

| 流 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **夺舍寄托** | 工具人练功法 → 寄托 → 夺舍到同一身体循环 | 快、套装可混搭、补件成本低 | 需接受夺舍 |
| **重生寄托** | 大哥多次玄牝重生/六道轮回丹换世寄托 | 可少杀门人、代入感强 | 慢；分神要「偿还」；改套成本极高 |

正道向可走重生流或符修自寄托；竞速/九劫多夺舍流。

### 3.4 战斗套印象（理解用，非唯一配方）

高赞寄托帖常见结构概念：

- 七杀段：杀意、御字、极剑、我剑、御剑术等寄在法宝（偷天针/天狼钉等）。  
- 两仪段：技巧之悟 / 大道之悟、归道剑、无离真法等。  
- 「十九件套」一类是 **件数目标**，具体技能表随版本与作者更新——实施前对照最新 TapTap 寄托帖，并在本机试穿验证。

驻扎铜陵山等进图挂机，可降低部分寄托分神消耗（社区技巧）。

### 3.5 寄托安全提示

- 先搞清：要的是战斗套、渡劫套还是功能套。  
- 普通难度往往低配套即可灭门；九劫再上满件。  
- 外门勿乱加「会飞/灵气护盾」等易被敌对 AI 当内门集火的特质（社区警告）。

## 4. 渡劫（飞升劫 / 道行劫 / 化形等）

### 4.1 本质

把劫云当「敌方法宝」：双方拼灵气与输出/防护；打光劫云灵气即成功，被劈死则失败（偶发人不死但废回凡人）。劫云从场地吸取灵气，有五行属性，可被克制。

### 4.2 场地

社区经典：**约 13×13** 克制属性房间或野外空地，中心可到、墙体用对应五行材料；注意劫云破坏范围，贵重物及时撤离。天气与地面属性也会改劫云灵气。

### 4.3 两条打法

| 路线 | 核心 | 优点 | 风险 |
|---|---|---|---|
| **肉身渡劫** | 堆护盾（合欢等护盾秘籍、龙鳞、玄甲符、龟壳/太一秘典等） | 稳、操作简单 | 慢 |
| **法宝渡劫** | 高威力法宝（如星髓针类）+ 幽剑/虚极/为剑/风神/同心/谷神等 | 快 | 法宝反噬抽干灵气则暴毙 |

通用：灵石/灵晶回灵；真罡丹等抬盾；加入战斗堂吃加成。

### 4.4 化形天劫（妖）

妖族专属压力；体修肉身抗劫通常比仙修硬抗更稳。开局看天劫天数——过早（数十天内）极难救。

### 4.5 渡劫的「副产物」

飞升劫成功可刷参悟；道行劫/飞升劫也可供分神。存在「工具人渡劫刷参悟」的进阶玩法（修炼堂 + 神泣/天道神丹等），属养老/竞速分支。

## 5. 体修进阶

### 5.1 与仙修的硬差异

- 丹药/符咒逻辑改变：多转化为精华或无效，不能照搬仙修药神。  
- 凡人期 **巧匠 / 岐黄 / 雅艺** 等级影响体修效率（评分≠等级）。  
- 气感等转化规则不同（如穿透、镇压等，见 BWIKI 蛮极条目）。  
- 秘体 = 体修的「装备技能」，淬出后要在装备页 **手动启用**。

### 5.2 功法获取印象

| 功法 | 常见获取 |
|---|---|
| 太古形意六合真体 | 约 104 天前后地图事件（社区） |
| 蛮极金身 | 万妖殿好感约 1200 首次拜山门等；人族常用 |
| 妖族圣体 / 败灭邪体等 | 万妖殿或其他条件 |

### 5.3 阶段优先级（守家向共识）

1. **淬体**：混元臂 + 双天盾腿肌肉等基础秘体件。  
2. **洗髓**：八极炼体刷脊柱与已有肢；词条优先服务秘体升级。  
3. **脱胎**：优先 **口、喉、胃（及肠）** 抬吞噬上限 → 再脑心等器官 → 再补肢。  
4. **万兽归息** 一类回气秘体：没发动机就战不动。  
5. **混元**：专属高阶秘体（蛮极不灭体等）按攻防定位选择。

吐纳精华受季节、天气、地块五行、风水吉凶、周围尸体等影响（BWIKI 表极长，实施时对照 Wiki/精华表，本站不整页粘贴以免过时错位）。

### 5.4 体修渡劫/战力

肉身堆盾抗化形与飞升；搜魂万妖殿来客可补秘体（涉及好感操控，属邪道向技巧，按需）。

## 6. 神修进阶（摘要）

- 资源：信仰（历练事件、代理点/神像、信徒与核心信徒）。  
- 开辟神国：信徒数、心境、神性、心绪、场地共同影响初始面积。  
- 风险三角：住房上限、可控神民（点心境）、建筑需求神民 → 怨气 → 信仰天劫。  
- 人选偏机缘/悟性；功法来源含卷轴、岭南事件、金匣等。  
- 节奏慢：建议仙修/体修稳定后再开；详表见 BWIKI 神道修行与神国专帖。

## 7. 灭门 / 攻坚编制（战力验收）

| 难度 | 常见验收标准（社区） |
|---|---|
| 普通 | 低配符修或低配寄托套即可单挑门派 |
| 九劫 | 满配两仪/双核 + 体修辅助 + 法宝位与护盾到位 |

编制建议：主 C（符修/两仪）+ 七杀打手团 + 体修嘲讽/抗线；阵法与偷天针等按你流派文档微调。  
「先打小门派练手 → 再挑战最高战力门派」比一上来硬刚更稳。

## 8. 周目路线模板

**稳健正道一周目**
