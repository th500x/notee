# 兵种适应性系统演示

## 🎯 系统概述

兵种适应性系统已成功集成到M2验证模块中，为部队编组增加了策略深度。

## ✨ 核心特性

### 1. 适应性等级
- **传奇 (20-25%)**: 橙色 - 如黄忠的弓兵25%，太史慈的弓兵25%
- **卓越 (15-19%)**: 紫色 - 如关羽的骑兵20%，张飞的步兵20%
- **优秀 (10-14%)**: 蓝色 - 如刘备的步兵15%，曹操的骑兵15%
- **良好 (5-9%)**: 绿色 - 基础适应性
- **不适应 (0%)**: 灰色 - 如张飞对弓兵0%

### 2. 战力计算公式
```
基础战力 = 武将属性(战斗+统率+智力) + 部队属性(攻击+防御+生命)
适应性加成 = 基础战力 × 适应性百分比
最终战力 = 基础战力 + 适应性加成
```

### 3. 实际示例

#### 关羽 + 虎豹骑（骑兵）
- 关羽属性: 战斗9 + 统率8.4 + 智力7 = 24.4
- 虎豹骑属性: 攻击80 + 防御60 + 生命100 = 240
- 基础战力: 264
- 骑兵适应性: 20%
- 适应性加成: 264 × 20% = 53
- **最终战力: 317**

#### 张飞 + 青龙偃月刀兵（步兵）
- 张飞属性: 战斗10 + 统率10 + 智力7 = 27
- 青龙偃月刀兵属性: 攻击80 + 防御60 + 生命100 = 240
- 基础战力: 267
- 步兵适应性: 20%
- 适应性加成: 267 × 20% = 53
- **最终战力: 320**

#### 黄忠 + 神臂弓兵（弓兵）
- 黄忠属性: 战斗8 + 统率10 + 智力7 = 25
- 神臂弓兵属性: 攻击90 + 防御50 + 生命80 = 220
- 基础战力: 245
- 弓兵适应性: 25%（传奇级）
- 适应性加成: 245 × 25% = 61
- **最终战力: 306**

## 🔧 技术实现

### 1. 数据格式
```javascript
troopAffinity: "infantry:15;cavalry:20;archer:5"
```

### 2. 解析函数
```javascript
const parseAffinityString = (affinityStr) => {
  const affinities = {};
  affinityStr.split(';').forEach(pair => {
    const [troopType, bonus] = pair.split(':');
    affinities[troopType] = parseInt(bonus) || 0;
  });
  return affinities;
};
```

### 3. 战力计算
```javascript
const affinityBonus = getAffinityBonus(character.troopAffinity, troop.troopType);
const finalPower = Math.floor(basePower * (1 + affinityBonus / 100));
```
