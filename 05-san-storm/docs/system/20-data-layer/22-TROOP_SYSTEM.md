## 📋 文档概述

本文档是部队系统的完整设计，包含部队卡系统、部队编组、部队展示、部队管理和部队战斗机制。部队系统是连接角色系统和战斗系统的核心桥梁。

**系统关系**：
```
部队系统（Troop System）
├── 部队卡系统（Troop Card System）- 核心
├── 部队编组系统（Formation System）
├── 阵型系统（Formation Tactics System）- 子系统
├── 部队展示系统（Display System）
├── 部队管理系统（Management System）
└── 部队战斗机制（Combat Mechanism）
```

**核心理念**：
- 🎖️ **部队卡** - 官职决定可使用的部队卡级别
- 👥 **兵力规模** - 不同稀有度部队卡有不同的兵力上限
- 🔥 **奋战机制** - 部队全灭会导致武将受伤
- 🏆 **金色特殊** - 金色部队卡每赛季仅限使用一次
- ⚠️ **极难获取** - 金色部队卡需要5-8级官职+特殊途径

## 🎖️ 一、部队卡系统

### 1.1 部队卡稀有度

部队卡分为5种稀有度，每种稀有度有不同的兵力上限：

| 稀有度 | 颜色 | 英文 | 单部队人数上限 | 说明 |
|--------|------|------|---------------|------|
| ⚪ 白 | 白色 | common | 200人 | 普通部队 |
| 💙 蓝 | 蓝色 | rare | 400人 | 稀有部队 |
| 💜 紫 | 紫色 | epic | 600人 | 史诗部队 |
| 🟠 橙 | 橙色 | legendary | 800人 | 传奇部队 |
| 🟡 金 | 金色 | core | 999人 | 核心部队（极难获取） |

### 1.2 金色部队卡特殊规则

**核心级（Core）部队卡**是最特殊的部队卡：

- 🟡 **每赛季仅限使用一次** - 使用后无法再次使用
- ⚠️ **无法恢复兵力** - 战斗损失的兵力无法补充
- 💀 **部队全灭后永久失效** - 兵力归零后该部队卡永久失效
- 🏆 **特殊纪念级别** - 代表最强大的核心部队
- ⚠️ **极难获取** - 需要5-8级官职（将军及以上）才能获取

**获取途径**：
- 赛季终极奖励（前10名）
- 重大历史事件奖励
- 特殊成就解锁
- 限时活动（极低概率）

**使用场景**：
- 赛季决战
- 关键历史事件
- 势力终极战役

**设计理念**：
- 增加策略性和紧张感
- 让金色部队卡成为传奇级存在
- 高级玩家的终极目标
