## ⚔️ 第一步：计算武将伤害

### A攻击B的武将伤害

```javascript
// 1. 基础物理伤害
基础伤害_A = 武力_A × 10 = 7.5 × 10 = 75

// 2. 勇气加成
勇气加成_A = 1 + (勇气_A / 20) = 1 + (7.0 / 20) = 1.35

// 3. 奋战值加成
奋战加成_A = (奋战值_A - 50) / 100 = (50 - 50) / 100 = 0

// 4. 最终武将伤害（不暴击）
武将伤害_A = 75 × 1.35 × (1 + 0) = 101.25
```

### B的武将防御

```javascript
// 1. 物理防御力

           = 52 / (52 + 100)
```

## 📝 补充说明

### 1. 伤害转换系数

**为什么需要伤害转换系数？**

因为武将伤害（60-200）和兵力损失（50-200）的数量级不同，需要一个转换系数。

**推荐系数**：
- 1点伤害 = 2-4兵力损失
- 建议从3开始测试

### 2. 反击伤害系数

**为什么反击伤害减半？**

- 避免互相伤害过高
- 鼓励主动攻击
- 增加策略深度

**可调整范围**：
- 0.3-0.6（30%-60%）

### 3. 部队防御公式

**为什么使用 防御/(防御+200)？**

- 防御收益递减
- 避免防御过高导致无敌
- 最高减免约50%（防御200时）

### 4. 数值平衡建议

**测试步骤**：
1. 先测试rare vs rare
2. 再测试common vs rare
3. 最后测试epic vs legendary
4. 根据结果微调系数

**调整方向**：
- 伤害太高 → 降低攻击力或提高防御力
- 伤害太低 → 提高攻击力或降低防御力
- 反击太强 → 降低反击系数
- 反击太弱 → 提高反击系数

## 🔄 重新设计：分离武将和部队伤害

### 新方案：武将伤害和部队伤害分别计算

**核心思路**：
- 武将伤害只影响对方武将（奋战值）
- 部队伤害只影响对方兵力
- 两者分开计算，互不干扰

**新公式**：

```javascript
// 1. 武将对武将伤害（影响奋战值）
武将伤害 = 武力 × 10 × (1 + 勇气/20) × (1 + (奋战值-50)/100)
武将防御减免 = (统率×5 + 武力×3) / (统率×5 + 武力×3 + 100)
实际武将伤害 = 武将伤害 × (1 - 武将防御减免)

// 2. 部队对部队伤害（影响兵力）
部队伤害 = 部队攻击力
部队防御减免 = 部队防御力 / (部队防御力 + 200)
实际部队伤害 = 部队伤害 × (1 - 部队防御减免)

// 3. 兵力损失
兵力损失 = 实际部队伤害 × 伤害转换系数
```
