## 🔄 系统间关系

### 数据流向

```
前端层（UI展示）
    ↕ API调用
核心系统层（游戏逻辑）
    ↕ 数据读取
数据层（静态数据）
```

### 依赖关系

```
前端层
├── 依赖 → 核心系统层（API）
└── 依赖 → 数据层（展示数据）

核心系统层
└── 依赖 → 数据层（读取数据）

数据层
└── 无依赖（独立存在）
```

## 🎯 文档编写规范

### 文档结构

每个系统文档应包含：

1. **📋 文档概述** - 系统简介、版本、状态
2. **🎯 核心功能** - 系统的主要功能
3. **📊 数据结构** - 数据格式和字段说明
4. **🔧 实现逻辑** - 核心算法和流程
5. **🎨 UI设计**（前端层） - 界面设计和交互
6. **📝 开发指南** - 开发注意事项

### 数据持久化标注

每个数据层文档开头必须标注：

```markdown
## 📋 数据持久化

**赛季数据**：🔄 每赛季重置
- 说明哪些数据会被清空

**跨赛季保留**：
- ✅ 说明哪些数据会被保留
- ❌ 说明哪些数据不会保留
```
