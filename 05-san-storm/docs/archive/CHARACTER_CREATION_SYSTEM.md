# 角色创建系统设计文档

## 📋 文档概述

本文档详细说明游戏的角色创建系统，包括完整的创建流程、属性随机机制、初始部队卡选择等核心设计。

**核心理念**：
- 🎮 **玩家即将领** - 玩家自己是可上阵的将领，可携带1支部队
- 🎲 **属性随机** - 3次随机×3个方案=9个方案供选择
- 🎴 **初始部队** - 3选2，白色部队卡（步兵/骑兵/弓兵）
- 🔒 **防止重随** - 退出游戏后仍保留9个方案
- ⚡ **快速上手** - 10-20分钟新手引导

---

### 流程概览

```
1. 服务器选择
```

## 🔐 账号激活管理系统

### 账号状态

**三种状态**：
- ✅ **active**（激活）- 正常游戏状态
- ⏸️ **inactive**（非激活）- 不活跃，释放名额
- 💎 **premium**（付费）- 付费用户，不受限制

### 非激活条件

**条件1：未完成新手引导**
- ⏰ **时限**：创建角色后8小时
- 📊 **判断**：`tutorialCompleted = false` 且超过8小时
- 🔄 **处理**：标记为非激活，释放服务器名额

**条件2：已完成新手引导**
- ⏰ **时限**：最后登录后16小时
- 📊 **判断**：`tutorialCompleted = true` 且超过16小时未登录
- 🔄 **处理**：标记为非激活，释放服务器名额

**例外：付费用户**
- 💎 **特权**：付费用户不受非激活限制
- ✅ **条件**：完成新手引导后开通付费功能
- 🔒 **保护**：账号永久保留，不会被标记为非激活

### 非激活处理逻辑

```javascript
// 检查账号是否应该被标记为非激活
function checkAccountInactivity(userId) {
  const user = db.users.findOne({ id: userId });
  
  // 付费用户不受限制
  if (user.accountType === 'premium') {
    return { shouldDeactivate: false, reason: '付费用户' };
  }
  
  const now = Date.now();
  const timeSinceLastLogin = now - user.lastLoginAt;
  
  // 条件1：未完成新手引导，超过8小时
  if (!user.tutorialCompleted) {
    const timeSinceCreation = now - user.createdAt;
    const eightHours = 8 * 60 * 60 * 1000;
    
    if (timeSinceCreation > eightHours) {
      return {
        shouldDeactivate: true,
        reason: '未完成新手引导超过8小时',
        timeSinceCreation: timeSinceCreation,
      };
    }
  }
  
  // 条件2：已完成新手引导，超过16小时未登录
  if (user.tutorialCompleted) {
    const sixteenHours = 16 * 60 * 60 * 1000;
    
    if (timeSinceLastLogin > sixteenHours) {
      return {
        shouldDeactivate: true,
        reason: '超过16小时未登录',
        timeSinceLastLogin: timeSinceLastLogin,
      };
    }
  }
  
  return { shouldDeactivate: false };
}

// 标记账号为非激活
function deactivateAccount(userId) {
  db.users.update(
    { id: userId },
    {
      $set: {
        accountStatus: 'inactive',
        deactivatedAt: Date.now(),
        deactivationReason: checkAccountInactivity(userId).reason,
      },
    }
  );
  
  // 释放服务器名额
  releaseServerSlot(userId);
  
  // 记录日志
  logAccountDeactivation(userId);
}

// 定时任务：每小时检查一次
function checkAllAccountsInactivity() {
  const users = db.users.find({
    accountStatus: 'active',
    accountType: { $ne: 'premium' }, // 排除付费用户
  });
  
  users.forEach(user => {
    const check = checkAccountInactivity(user.id);
    if (check.shouldDeactivate) {
      deactivateAccount(user.id);
    }
  });
}
```

### 重新激活逻辑

**重新登录处理**：
```javascript
// 用户重新登录
function handleUserLogin(userId) {
  const user = db.users.findOne({ id: userId });
  
  // 更新最后登录时间
  db.users.update(
    { id: userId },
    {
      $set: {
        lastLoginAt: Date.now(),
      },
    }
  );
  
  // 如果账号是非激活状态
  if (user.accountStatus === 'inactive') {
    // 检查势力是否已满
    const faction = db.factions.findOne({ id: user.factionId });
    const factionPlayerCount = db.users.count({
      factionId: user.factionId,
      accountStatus: 'active',
      tutorialCompleted: true,
    });
    
    if (factionPlayerCount < faction.maxPlayers) {
      // 势力未满，重新激活账号
      db.users.update(
        { id: userId },
        {
          $set: {
            accountStatus: 'active',
            reactivatedAt: Date.now(),
          },
        }
      );
      
      return {
        allowed: true,
        message: '欢迎回来！',
        serverId: user.serverId,
        factionId: user.factionId,
      };
    } else {
      // 势力已满，引导到其他服务器
      const suggestedServers = getSuggestedServers();
      
      return {
        allowed: false,
        message: '你的势力已满员，请选择其他服务器',
        currentFaction: faction.name,
        suggestedServers: suggestedServers,
      };
    }
  }
  
  // 账号正常，直接登录
  return {
    allowed: true,
    serverId: user.serverId,
    factionId: user.factionId,
  };
}
```

```javascript
// 每5分钟更新一次
schedule.every('5 minutes').do(() => {
  updateServerStatus();
});

function updateServerStatus() {
  const servers = db.servers.find({ season: 'S1' });
  
  servers.forEach(server => {
    const activePlayerCount = db.users.count({
      serverId: server.id,
      accountStatus: 'active',
      tutorialCompleted: true,
    });
    
    const onlinePlayerCount = db.users.count({
      serverId: server.id,
      accountStatus: 'active',
      isOnline: true,
    });
    
    const status = getServerStatus(activePlayerCount);
    
    db.servers.update(
      { id: server.id },
      {
        $set: {
          activePlayerCount: activePlayerCount,
          onlinePlayerCount: onlinePlayerCount,
          status: status.status,
          lastUpdateAt: Date.now(),
        },
      }
    );
  });
}
```

#### 属性随机算法

**核心机制**：
- 🎲 **3次随机** - 每次生成3个方案（A/B/C型）
- 📊 **9个方案** - 共9个方案供玩家选择
- 🔒 **防止重随** - 退出游戏后仍保留这9个方案
- ⚖️ **平衡设计** - 偏高属性比其他高1.0-1.5

**方案类型**：

| 类型 | 偏高属性 | 其他属性 | 总属性点 |
|------|---------|---------|---------|
| A型 | 运气+勇气 | 略低 | 44.0-46.0 |
| B型 | 统率+武力 | 略低 | 44.0-46.0 |
| C型 | 智力+政治+魅力 | 略低 | 44.0-46.0 |

**算法实现**：

```javascript
// 属性随机算法
function generateAttributeScheme(type) {
  const baseTotal = 44.0 + Math.random() * 2.0; // 44.0-46.0
  const attributes = {
    luck: 5.0,
    courage: 5.0,
    command: 5.0,
    combat: 5.0,
    intelligence: 5.0,
    politics: 5.0,
    charisma: 5.0,
  };
  
  let remainingPoints = baseTotal - 35.0; // 7个属性，基础5.0
  
  // 根据类型分配偏高属性
  if (type === 'A') {
    // 运气+勇气偏高
    const bonus = 1.0 + Math.random() * 0.5; // 1.0-1.5
    attributes.luck += bonus;
    attributes.courage += bonus;
    remainingPoints -= bonus * 2;
  } else if (type === 'B') {
    // 统率+武力偏高
    const bonus = 1.0 + Math.random() * 0.5; // 1.0-1.5
    attributes.command += bonus;
    attributes.combat += bonus;
    remainingPoints -= bonus * 2;
  } else if (type === 'C') {
    // 智力+政治+魅力偏高（军师型）
    const bonus = 1.0 + Math.random() * 0.5; // 1.0-1.5
    attributes.intelligence += bonus;
    attributes.politics += bonus;
    attributes.charisma += bonus;
    remainingPoints -= bonus * 3;
  }
  
  // 随机分配剩余点数
  const keys = Object.keys(attributes);
  while (remainingPoints > 0.1) {
    const key = keys[Math.floor(Math.random() * keys.length)];
    const add = Math.min(0.1, remainingPoints);
    attributes[key] += add;
    remainingPoints -= add;
  }
  
  // 四舍五入到小数点后一位
  for (const key in attributes) {
    attributes[key] = Math.round(attributes[key] * 10) / 10;
  }
  
  return attributes;
}

// 生成9个方案
function generateNineSchemes() {
  const schemes = [];
  
  for (let i = 0; i < 3; i++) {
    schemes.push({
      id: `scheme_A${i + 1}`,
      type: 'A',
      characterType: 'balanced', // 文武双全
      name: `方案A${i + 1}（文武双全）`,
      attributes: generateAttributeScheme('A'),
    });
    
    schemes.push({
      id: `scheme_B${i + 1}`,
      type: 'B',
      characterType: 'military', // 武官型
      name: `方案B${i + 1}（武官型）`,
      attributes: generateAttributeScheme('B'),
    });
    
    schemes.push({
      id: `scheme_C${i + 1}`,
      type: 'C',
      characterType: 'strategist', // 军师型
      name: `方案C${i + 1}（军师型）`,
      attributes: generateAttributeScheme('C'),
    });
  }
  
  return schemes;
}
```

**防止重随机制**：

```javascript
// 保存9个方案到数据库
function saveSchemes(userId, schemes) {
  // 保存到数据库
  db.characterCreation.insert({
    userId: userId,
    schemes: schemes,
    createdAt: Date.now(),
    expiresAt: Date.now() + 7 * 24 * 60 * 60 * 1000, // 7天后过期
  });
}

// 检查是否已有方案
function checkExistingSchemes(userId) {
  const data = db.characterCreation.findOne({ userId: userId });
  
  if (data && data.expiresAt > Date.now()) {
    // 方案未过期，返回已有方案
    return data.schemes;
  } else {
    // 方案已过期或不存在，生成新方案
    const schemes = generateNineSchemes();
    saveSchemes(userId, schemes);
    return schemes;
  }
}
```

**设计理念**：
1. ✅ **防止无限重随** - 只能随机3次，共9个方案
2. ✅ **退出保留** - 退出游戏后仍保留这9个方案
3. ✅ **7天过期** - 7天后方案过期，可重新随机
4. ✅ **平衡设计** - 偏高属性不会高太多（1.0-1.5）

## 🎯 设计亮点

### 1. 玩家即将领

**核心设计**：
- ✅ **玩家自己是将领** - 可上阵，可携带1支部队
- ✅ **主角定位** - 玩家是游戏的主角
- ✅ **成长系统** - 玩家角色可以升级、晋升官职
- ✅ **战斗参与** - 玩家可以直接参与战斗

**与NPC武将的区别**：
- 玩家角色：可携带1支部队，可升级，可晋升官职
- NPC武将：可携带1支部队，可升级，但官职固定

### 2. 属性随机机制

**3次随机×3个方案**：
- ✅ **9个方案** - 给玩家足够的选择空间
- ✅ **防止重随** - 避免无限重随，保持公平
- ✅ **退出保留** - 退出游戏后仍保留方案
- ✅ **7天过期** - 7天后可重新随机

**平衡设计**：
- ✅ **偏高属性** - 比其他属性高1.0-1.5
- ✅ **总属性点** - 44.0-46.0，保持平衡
- ✅ **三种类型** - A型（运气+勇气）、B型（统率+武力）、C型（智力+政治+魅力）

### 3. 初始部队卡

**3选2机制**：
- ✅ **多样化** - 步兵、骑兵、弓兵
- ✅ **策略性** - 不同组合有不同玩法
- ✅ **公平性** - 所有玩家都是白色部队卡

### 4. 新手引导

**10-20分钟**：
- ✅ **快速上手** - 不会太长，不会太短
- ✅ **完整体验** - 涵盖核心玩法
- ✅ **丰厚奖励** - 2次抽卡机会

### 5. 服务器负载管理

**实时状态展示**：
- ✅ **负载显示** - 空闲/热门/拥挤/满编状态
- ✅ **智能分流** - 满编服务器引导到其他服务器
- ✅ **负载均衡** - 多个S1服务器分散玩家
- ✅ **在线统计** - 实时显示在线人数

**满编保护**：
- ✅ **新玩家限制** - 满编不接受新注册
- ✅ **老玩家优先** - 已有账号可继续游戏（势力未满）
- ✅ **自动释放** - 不活跃账号释放名额

### 6. 账号激活管理

**自动清理机制**：
- ✅ **8小时规则** - 未完成引导超过8小时标记为非激活
- ✅ **16小时规则** - 完成引导超过16小时未登录标记为非激活
- ✅ **付费保护** - 付费用户永不被清理
- ✅ **重新激活** - 玩家回归可继续游戏

**公平性保障**：
- ✅ **名额释放** - 不活跃账号释放服务器名额
- ✅ **势力平衡** - 避免势力人数失衡
- ✅ **新玩家机会** - 给新玩家更多进入机会
