## 常见问题

### Q1: 属性值超过10怎么办？

**A**: 这是数据错误，需要重新生成数据：
```bash
node tools/update-hero-csv.cjs
node tools/hero-csv-to-json.cjs
```

### Q2: 页面还显示"人生阶段"怎么办？

**A**: 运行术语替换脚本：
```bash
node tools/replace-terminology.cjs
```

### Q3: 武将列表为空怎么办？

**A**: 检查数据文件是否存在：
- `public/data/shared/characters.json`

如果不存在，运行：
```bash
node tools/hero-csv-to-json.cjs
```

### Q4: 生涯详情弹窗打不开怎么办？

**A**: 检查是否有 `life-stages.json` 文件：
- `public/data/shared/life-stages.json`

如果不存在，需要运行：
```bash
node tools/calculate-life-stages.cjs
```
