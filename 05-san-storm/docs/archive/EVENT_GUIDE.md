# Excel 事件管理指南

## 📊 快速开始

### 1. 打开模板

用 **Excel** 或 **WPS** 打开 `event-template.csv`

### 2. 填写事件

按照表格列填写，参考下面的说明

### 3. 保存

**重要**：保存为 **CSV UTF-8 (逗号分隔)** 格式

文件名：`event-data.csv`

### 4. 转换

```bash
node tools/csv-to-event.js
```

## 📋 表格列详解

### 基础信息（必填）

| 列名 | 说明 | 示例 | 必填 |
|------|------|------|------|
| 事件ID | 唯一标识，四位数 | event_tk_0001 | ✅ |
| 事件名称 | 显示给玩家的标题 | 桃园结义 | ✅ |
| 事件类型 | historical/fiction/daily | historical | ✅ |
| 分类 | three_kingdoms等 | three_kingdoms | ✅ |
| 事件描述 | 事件的文字描述 | 你在桃园遇到... | ✅ |

### 触发条件（可选）

| 列名 | 说明 | 示例 | 格式 |
|------|------|------|------|
| 触发地点 | 多个用逗号分隔 | 涿郡,桃园 | 文本,文本 |
| 最低等级 | 玩家等级要求 | 1 | 数字 |
| 需求因子 | 因子:值 | charisma:60 | 因子:值 |
| 触发概率 | 0-1之间的小数 | 0.15 | 0.15 |
| 触发场景 | 多个用逗号分隔 | move,idle | 文本,文本 |

### 选项A（至少一个选项）

| 列名 | 说明 | 示例 | 格式 |
|------|------|------|------|
| 选项A_ID | 选项标识 | option_a | option_a |
| 选项A_文本 | 显示给玩家 | 欣然接受 | 文本 |
| 选项A_条件类型 | always/factor_check | factor_check | 文本 |
| 选项A_因子要求 | 因子:最小值:权重 | charisma:70:0.6 | 因子:值:权重 |
| 选项A_成功文本 | 成功时显示 | 你们结为兄弟 | 文本 |
| 选项A_失败文本 | 失败时显示（可选） | 你言语不当 | 文本 |

### 选项A奖励（可选）

| 列名 | 说明 | 示例 | 格式 |
|------|------|------|------|
| 选项A_成功奖励_经验 | 经验值 | 1000 | 数字 |
| 选项A_成功奖励_金币 | 金币 | 500 | 数字 |
| 选项A_成功奖励_物品 | 多个用逗号分隔 | 桃园令牌,宝剑 | 文本,文本 |
| 选项A_成功奖励_属性 | 属性:值 | charisma:5 | 属性:值 |
| 选项A_成功奖励_关系 | NPC:值 | 刘备:30,关羽:20 | NPC:值,NPC:值 |
| 选项A_成功奖励_称号 | 称号名称 | 桃园义士 | 文本 |

### 选项A失败奖励（可选）

| 列名 | 说明 | 示例 |
|------|------|------|
| 选项A_失败奖励_经验 | 失败时的经验 | 100 |
| 选项A_失败奖励_金币 | 失败时的金币 | 50 |
| 选项A_失败奖励_属性 | 失败时的属性变化 | charisma:-5 |

### 选项B（可选）

所有列名同选项A，只是把"A"改成"B"

### 元数据（可选）

| 列名 | 说明 | 示例 |
|------|------|------|
| 难度 | easy/normal/hard/extreme | easy |
| 稀有度 | common/rare/epic/legendary | rare |
| 标签 | 多个用逗号分隔 | 结义,刘备,关羽 |
| 作者 | 创作者 | 策划组 |
| 版本 | 版本号 | 1.0 |
| 备注 | 任意备注 | 这是经典事件 |

## 💡 填写技巧

### 1. 复制粘贴

- 复制示例行
- 修改ID和内容
- 快速创建新事件

### 2. 使用公式

```excel
# 自动生成ID
=CONCATENATE("event_tk_", TEXT(ROW()-1, "0000"))

# 结果：event_tk_0001, event_tk_0002...
```

### 3. 数据验证

设置下拉列表：
- 事件类型：historical, fiction, daily
- 难度：easy, normal, hard, extreme
- 稀有度：common, rare, epic, legendary

### 4. 条件格式

高亮显示：
- 空白的必填项（红色）
- 重复的事件ID（黄色）
- 高难度事件（橙色）

## 🔍 检查清单

### 保存前检查

- [ ] 事件ID唯一且符合规范（四位数）
- [ ] 必填项都已填写
- [ ] 触发概率在0-1之间
- [ ] 因子格式正确
- [ ] 没有多余的空行
- [ ] 保存为 CSV UTF-8 格式

### 转换前检查

- [ ] 文件名为 `event-data.csv`
- [ ] 文件在 `tools` 目录下
- [ ] 编码为 UTF-8
