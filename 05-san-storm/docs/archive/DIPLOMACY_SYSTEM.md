# 外交系统设计文档

## 📋 文档概述

本文档详细说明游戏中的外交系统设计，包括外交状态、申请机制、AI决策、谈判流程等核心机制。

**核心理念**：
- 🤝 **远交近攻** - 基于地缘政治的外交策略
- ⚖️ **动态平衡** - 通过外交调整势力强弱
- 🎯 **玩家主导** - 高级官职玩家可以影响外交
- 🤖 **AI决策** - 君主AI根据形势做出决策
- 🌐 **多方谈判** - 七大势力AI互相谈判

## 🌍 外交状态

### 三种外交关系

| 状态 | 图标 | 说明 | 效果 |
|------|------|------|------|
| **联合** | 🤝 | 同盟关系 | 不可互相攻击，共享视野，互相支援 |
| **中立** | ⚪ | 默认状态 | 可以攻击，无特殊效果 |
| **敌对** | ⚔️ | 敌对关系 | 攻击伤害+10%，掠夺资源+20% |

## 🎯 外交申请机制

### 申请权限

**有权申请的官职**：
- ⭐⭐⭐ **大将军**（第1名）- 每周可提2个申请
- ⭐⭐ **将军**（第2-5名）- 每周可提1个申请

**申请类型**：
- 🤝 **联合申请** - 提议与某势力结盟
- ⚔️ **敌对申请** - 提议与某势力敌对
- ⚪ **中立申请** - 提议解除联合/敌对，恢复中立

### 申请时间

**每周申请窗口**：
- 开放时间：每周一 00:00 - 周三 23:59
- 截止时间：周三 23:59
- 决策时间：周四 00:00（AI决策）
- 谈判时间：周四 01:00 - 03:00（AI谈判）
- 公布时间：周四 08:00（全服公告）


### 申请流程

```
周一-周三：玩家提交外交申请
    ↓
周四 00:00：君主AI收集所有申请
    ↓
周四 00:00-01:00：君主AI决策（同意/拒绝）
    ↓
周四 01:00-03:00：七大势力AI谈判
    ↓
周四 03:00：确定最终外交关系
    ↓
周四 08:00：全服公告新的外交关系
    ↓
周四 08:00起：新外交关系生效
```

### 联合申请决策树

```
收到联合申请
    ↓
是否接壤？
    ├─ 否 → 偏向同意（80%概率）
    │       理由：远交，无领土冲突
    │
    └─ 是 → 进入详细判断
            ↓
        对方是否强势？
            ├─ 是（战力>我方×1.5）→ 偏向同意（70%）
            │   理由：避免被攻击，寻求保护
            │
            ├─ 否（战力<我方×0.7）→ 偏向拒绝（70%）
            │   理由：对方太弱，联合无益
            │
            └─ 相当（0.7-1.5倍）→ 综合判断（50%）
                ↓
            是否有共同敌人？
                ├─ 是 → 同意（80%）
                │   理由：联合对抗共同敌人
                │
                └─ 否 → 根据AI性格决定
                    ├─ 谨慎型（刘备）→ 同意（60%）
                    ├─ 野心型（曹操）→ 拒绝（60%）
                    └─ 中立型（孙坚）→ 随机（50%）
```

### 敌对申请决策树

```
收到敌对申请

    ├─ 否 → 偏向拒绝（80%概率）
```

## 🌐 七大势力AI谈判

### 谈判流程

**阶段1：收集决策结果**（周四 01:00）
```javascript
// 每个势力AI的决策结果
const decisions = {
  刘备: { 联合: ['汉室'], 敌对: ['董卓', '黄巾'] },
  曹操: { 联合: ['汉室'], 敌对: ['董卓', '袁绍', '黄巾'] },
  孙坚: { 联合: [], 敌对: ['黄巾'] },
  // ...
};
```

**阶段2：双向匹配**（周四 01:30）
```javascript
// 联合必须双方都同意
if (刘备想联合汉室 && 汉室想联合刘备) {
  建立联合关系 ✅
}

// 敌对只需一方同意
if (刘备想敌对董卓 || 董卓想敌对刘备) {
  建立敌对关系 ✅
}
```

**阶段3：冲突解决**（周四 02:00）
```javascript
// 情况1：A想联合B，但B想敌对A
if (刘备想联合曹操 && 曹操想敌对刘备) {
  结果 = 敌对 ⚔️  // 敌对优先
}

// 情况2：A想联合B和C，但B和C互相敌对
if (刘备想联合曹操 && 刘备想联合袁绍 && 曹操敌对袁绍) {
  // 刘备必须选择一方
  根据战力和地缘选择 → 保留更有利的联合
}
```

**阶段4：平衡检查**（周四 02:30）
```javascript
// 检查是否出现超级联盟（3个以上势力联合）
if (联合势力数 >= 3) {
  // 触发平衡机制
  其他势力自动形成对抗联盟
}

// 检查是否有势力被孤立（所有势力都敌对）
if (某势力被所有势力敌对) {
  // 触发保护机制
  强制解除部分敌对关系
}
```

**阶段5：最终确定**（周四 03:00）
```javascript
// 生成最终外交关系矩阵
const finalDiplomacy = {
  刘备: { 联合: ['汉室'], 敌对: ['董卓', '黄巾'], 中立: ['曹操', '孙坚', '袁绍'] },
  曹操: { 联合: ['汉室'], 敌对: ['董卓', '袁绍', '黄巾'], 中立: ['刘备', '孙坚'] },
```

## 📊 外交效果

### 联合关系效果 🤝

**战斗限制**：
- ❌ 不可互相攻击
- ❌ 不可攻击盟友的城市
- ✅ 可以驻军盟友城市（防守）

**视野共享**：
- ✅ 共享地图视野
- ✅ 共享敌军动向
- ✅ 共享资源点位置

**互相支援**：
- ✅ 可以派兵支援盟友战斗
- ✅ 可以赠送资源（每周1次）
- ✅ 可以共享情报

**贸易加成**：
- ✅ 资源交易手续费-50%
- ✅ 盟友城市购物折扣-10%

### 敌对关系效果 ⚔️

**战斗加成**：
- ✅ 攻击伤害+10%
- ✅ 掠夺资源+20%
- ✅ 攻城速度+15%

**声望奖励**：
- ✅ 击败敌对势力玩家，声望+50%
- ✅ 攻占敌对势力城市，声望+100%

**任务奖励**：
- ✅ 针对敌对势力的任务奖励+30%

### 中立关系效果 ⚪

**标准状态**：
- ✅ 可以攻击
- ✅ 无特殊加成
- ✅ 无特殊限制

- 联合汉室对抗董卓

## 🔄 动态平衡机制

### 自动平衡触发

**触发条件**：
```javascript
// 条件1：某势力战力过强
if (某势力战力 > 平均战力 × 2.0) {
  触发：其他势力倾向于联合对抗
}

// 条件2：某势力被孤立
if (某势力被所有势力敌对) {
  触发：强制解除部分敌对，避免被围攻
}

// 条件3：超级联盟出现
if (联合势力数 >= 3 && 联合总战力 > 全服战力 × 0.6) {
  触发：其他势力自动形成对抗联盟
}
```

### 仙人AI干预

**仙人降临时**：
- 如果某势力被孤立 → 仙人赐予吉兆
- 如果某联盟过强 → 仙人赐予天灾
- 配合外交系统，双重平衡
