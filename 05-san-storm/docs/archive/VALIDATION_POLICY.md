## 📋 验证规则

### ✅ 对已存在的角色

**只验证总属性点**，不验证武力组/智力组比例。

**原因**：
- 已存在的角色属性是根据历史人物特点精心设计的
- 强制比例会破坏角色的个性化设计
- 比例规则只是参考，不是硬性要求

**验证内容**：
```javascript
// 只检查总属性点是否在期望范围内
if (total < expectedRange.min || total > expectedRange.max) {
  // 报错
}
```

---

### 🆕 对新创建的角色

**建议遵循武力组/智力组比例规则**，但不强制。

**比例规则**（仅供参考）：

#### Military（武官型）
```
武力组 / 智力组 = 1.2 - 1.5
武力组 = command + combat
智力组 = intelligence + politics + charisma
```

**示例**：
- 武力组 = 18.0
- 智力组 = 15.0
- 比例 = 18.0 / 15.0 = 1.2 ✅

#### Strategist（军师型）
```
智力组 / 武力组 = 1.2 - 1.5
```

**示例**：
- 智力组 = 24.0
- 武力组 = 16.0
- 比例 = 24.0 / 16.0 = 1.5 ✅

#### Balanced（文武双全）
```
无严格比例要求
总属性点比其他类型高2点
```

## 🎯 设计理念

### 为什么不强制比例？

1. **尊重历史**：历史人物的属性应该基于史实，而不是数学公式
2. **保持个性**：每个角色都有独特的属性分配，这是游戏的魅力所在
3. **灵活性**：设计师应该有自由度来调整角色属性
4. **平衡性**：总属性点已经保证了平衡性，比例只是锦上添花

### 比例规则的作用

比例规则主要用于：
- **新角色创建**：提供一个参考标准
- **快速生成**：批量生成角色时的算法依据
- **类型识别**：帮助识别角色的类型（military/strategist/balanced）

但不应该用于：
- ❌ 强制修改已存在的角色
- ❌ 限制设计师的创意
- ❌ 破坏角色的个性化设计

## 📝 修正流程

### 修正总属性点不符的角色

1. 打开 `tools/hero-template.csv`
2. 找到需要修正的角色
3. 调整任意属性，使总属性点符合期望范围
4. 保存CSV文件
5. 运行 `node tools/hero-csv-to-json.cjs` 转换
6. 运行 `node tools/hero-list-errors-only.cjs` 验证

### 创建新角色

1. 在 `tools/hero-template.csv` 中添加新角色
2. 参考比例规则设置属性（可选）
3. 确保总属性点在期望范围内
4. 运行 `node tools/hero-csv-to-json.cjs` 转换
5. 运行 `node tools/hero-list-errors-only.cjs` 验证
