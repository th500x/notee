## 二、数据结构

### 当前数据源

前端使用以下数据文件：

1. **public/data/shared/characters.json**
   - 武将基础数据
   - 包含S1赛季的属性、技能、生涯等信息
   - 从 `tools/hero-template.csv` 生成

2. **public/data/shared/life-stages.json**（待生成）
   - 9个赛季的生涯数据
   - 每个武将在不同赛季的属性变化
   - 需要运行 `tools/calculate-life-stages.cjs` 生成

### 数据字段

**characters.json** 中的生涯相关字段：
```json
{
  "id": "char_san_1101",
  "name": "刘备",
  "age": 23,
  "stage": "early",  // 生涯：early/peak/late/death
  "birthYear": 161,
  "deathYear": 223,
  // ... 其他字段
}
```

**life-stages.json** 中的数据结构：
```json
{
  "lifeStages": {
    "char_san_1101": {
      "id": "char_san_1101",
      "name": "刘备",
      "birthYear": 161,
      "deathYear": 223,
      "baseAttributes": { /* 基础属性 */ },
      "seasons": [
        {
          "season": "S1",
          "year": 184,
          "age": 23,
          "stage": "early",
          "stageName": "茅庐",
          "stageIcon": "🌱",
          "attributes": { /* 修正后属性 */ },
          "total": 55.1
        }
        // ... S2-S9
      ]
    }
  }
}
```
