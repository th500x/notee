# 官职系统设计文档

## 📋 文档概述

本文档详细说明游戏中的官职系统设计，包括官职等级、晋升机制、部队卡系统等核心机制。

**核心理念**：
- 📈 **成长路径** - 从军候到大将军的完整晋升路径
- 🎯 **专精方向** - 步兵、骑兵、攻击、防守等不同专精
- 🏆 **唯一官职** - 高级官职全服唯一，增加竞争性
- 🎴 **部队卡** - 官职决定可使用的部队卡级别
- ⚔️ **任务晋升** - 通过完成任务积累进度晋升

## 📈 官职晋升机制

### 任务积分系统

**任务难度**：
- 🟢 **普通任务** - 积分+1
- 🔴 **困难任务** - 积分+2

**晋升方式**：
- 完成任务积累积分
- 达到所需积分自动晋升
- 唯一官职需要竞争排名

### 晋升所需积分（待设计）

**初步建议**：
```
1级→2级：10积分
2级→3级：20积分
3级→4级：40积分
4级→5级：80积分（+竞争排名）
5级→6级：150积分（+竞争排名）
6级→7级：250积分（+竞争排名）
7级→8级：400积分（+竞争排名）
```

### 唯一官职竞争机制

**5-8级官职竞争**：

1. **达到积分要求** - 必须先达到晋升所需积分
2. **势力内排名** - 在势力内按积分排名
3. **官职空缺** - 该官职必须有空缺
4. **自动晋升** - 满足条件后自动晋升

**示例**：
```
讨虏将军（5级，唯一）：
- 需要80积分
- 势力内排名前18（5级共18个官职）
- 讨虏将军空缺
- 满足条件自动晋升
```

## 🎯 设计亮点

### 1. 历史真实性

**官职名称**：
- 全部来自汉末三国真实官职
- 讨虏、破虏、荡寇等征伐系官职
- 四安、四平、四镇、四征等方位官职
- 骠骑、车骑、大司马、大将军等顶级官职

**官职等级**：
- 符合汉末官职体系
- 从军候（低级军官）到大将军（最高军职）
- 完整的晋升路径

### 2. 专精系统

**多样化发展**：
- 步兵专精 - 适合防守型玩家
- 骑兵专精 - 适合机动型玩家
- 攻击专精 - 适合进攻型玩家
- 防守专精 - 适合守城型玩家
- 攻防专精 - 适合平衡型玩家

**策略选择**：
- 玩家可以根据自己的玩法选择专精
- 不同专精有不同的强化效果
- 增加游戏的策略深度

### 3. 唯一官职竞争

**竞争机制**：
- 5-8级官职全服唯一
- 增加玩家竞争性
- 提升官职的荣誉感

**平衡设计**：
- 5级官职有18个（征伐6+勇武6+镇抚6）
- 给更多玩家晋升机会
- 避免过度集中

### 4. 部队卡系统

**渐进式成长**：
- 官职越高，可用部队卡越强
- 从200人到999人的成长路径
- 给玩家明确的成长目标

**金色部队卡**：
- 每赛季仅限使用一次
- 无法恢复兵力
- 增加策略性和紧张感
- 仅限AI君主使用

### 5. 权限系统

**逐步解锁**：
- 官职越高，权限越多
- 从普通战斗到外交决策
- 给玩家成长的动力

**外交权限**：
- 6级以上可提出外交建议
- 8级大将军每周2次
- 配合外交系统
