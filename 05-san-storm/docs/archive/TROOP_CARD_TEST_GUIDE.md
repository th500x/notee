## 🐛 常见问题排查

### 问题1：图标不显示

**可能原因**：
- 图标文件路径错误
- 图标文件名不匹配
- 图标文件不存在

**解决方法**：
1. 检查文件路径：`public/assets/troops/{troop_id}.png`
2. 检查文件名是否与troop.id完全匹配
3. 检查浏览器控制台是否有404错误
4. 确认图标文件已正确放置

### 问题2：图标模糊

**可能原因**：
- 图标尺寸太小
- 图标被过度缩放

**解决方法**：
1. 确保图标尺寸≥256×256px
2. 推荐使用400×400px
3. 使用高质量PNG格式

### 问题3：卡牌布局错乱

**可能原因**：
- CSS样式冲突
- Tailwind CSS未正确加载

**解决方法**：
1. 检查浏览器控制台错误
2. 清除浏览器缓存
3. 重启开发服务器

### 问题4：数据不显示

**可能原因**：
- troops.json文件不存在
- JSON格式错误
- 数据加载失败

**解决方法**：
1. 运行 `node tools/troop-csv-to-json.cjs`
2. 检查 `public/data/shared/troops.json` 是否存在
3. 验证JSON格式是否正确
4. 检查浏览器控制台错误
