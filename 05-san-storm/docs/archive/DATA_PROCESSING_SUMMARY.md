## 🔧 处理工具

### 1. process-hero-data.cjs

**功能**：
- 根据年龄自动判断 stage
- 为缺失属性的角色生成属性数据
- 输出处理后的CSV文件

**使用方法**：
```bash
node tools/process-hero-data.cjs
```

**输出**：`tools/hero-template-processed.csv`

### 2. csv-to-json.cjs

**功能**：
- 将处理后的CSV转换为JSON格式
- 只处理S1赛季的角色
- 自动生成角色ID

**使用方法**：
```bash
node tools/csv-to-json.cjs
```

**输出**：`public/data/shared/characters.json`

### 3. validate-attributes.cjs

**功能**：
- 验证所有角色属性是否符合规则
- 生成详细的验证报告
- 提供调整建议

**使用方法**：
```bash
node tools/validate-attributes.cjs
```

## ⚠️ 当前问题

### 验证结果

运行验证工具后发现：
- ✅ **完全符合规则**：约10个角色
- ⚠️ **有警告**：约18个角色（比例略超范围）
- ❌ **有错误**：约91个角色（需要调整）

### 主要问题

1. **Military类型比例问题**
   - 很多military类型的武力组/智力组比例低于1.2
   - 原因：CSV中手动填写的属性未按规则设计

2. **Strategist类型比例问题**
   - 部分strategist类型的智力组/武力组比例超过1.5
   - 原因：智力组属性设置过高

3. **总属性点不符**
   - 部分角色总属性点不在期望范围内
   - 原因：手动填写时未考虑稀有度和阶段修正

## 📝 属性规则参考

### 总属性点公式

```
总属性点 = 基础点数（稀有度 + 类型） × 阶段修正
```

### 基础点数表

| 稀有度 | military/strategist | balanced |
|--------|---------------------|----------|
| core | 50-60 | 52-62 |
| legendary | 56-60 | 58-62 |
| epic | 52-56 | 54-58 |
| rare | 48-52 | 50-54 |
| common | 44-48 | 46-50 |

### 类型分配规则

**Military（武官型）**：
```
武力组（command + combat） = 智力组（intelligence + politics + charisma） × 1.2-1.5
```

**Strategist（军师型）**：
```
智力组（intelligence + politics + charisma） = 武力组（command + combat） × 1.2-1.5
```

**Balanced（文武双全）**：
- 无严格比例要求
- 总属性点比其他类型高2点

## 🔄 数据更新流程

### 添加新武将

1. 在 `tools/hero-template.csv` 中添加新行
2. 填写基础信息（name, rarity, age, faction, CHARACTER_TYPES等）
3. 运行 `node tools/process-hero-data.cjs` 生成属性
4. 运行 `node tools/csv-to-json.cjs` 转换为JSON
5. 运行 `node tools/validate-attributes.cjs` 验证数据
6. 根据验证结果手动调整

### 修改现有武将

1. 直接在 `tools/hero-template.csv` 中修改
2. 重新运行处理和转换脚本
3. 验证数据

### 批量调整

1. 修改 `process-hero-data.cjs` 中的生成算法
2. 重新处理所有数据
3. 验证并微调
