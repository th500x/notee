# 部队卡匹配机制优化

**日期**: 2026-02-08  
**版本**: v1.1.0（调整为-10%惩罚）  
**状态**: ✅ 设计完成

---

## 📋 优化概述

优化武将稀有度与部队卡的匹配机制，允许低稀有度武将携带高一级部队卡，但有-10%属性惩罚。

---

## 🔄 设计变更

### 原设计

**严格匹配**：武将只能携带同稀有度的部队卡

| 武将稀有度 | 可携带部队卡 | 兵力 | 部队属性 |
|-----------|-------------|------|---------|
| ⚪ 白色 | ⚪ 白色 | 200人 | 100% |
| 🔵 蓝色 | 🔵 蓝色 | 400人 | 100% |
| 🟣 紫色 | 🟣 紫色 | 600人 | 100% |
| 🟠 橙色 | 🟠 橙色 | 800人 | 100% |
| 🟡 金色 | 🟡 金色 | 999人 | 100% |

**问题**：
- ❌ 初期玩家兵力不足
- ❌ 低稀有度武将价值低
- ❌ 部队卡资源利用率低
- ❌ 成长曲线有明显断层

### 新设计

**灵活匹配**：武将可以携带同级或高一级部队卡

| 武将稀有度 | 可携带部队卡 | 兵力 | 部队属性 | 说明 |
|-----------|-------------|------|---------|------|
| ⚪ 白色 | ⚪ 白色 | 200人 | 100% | 完美匹配 |
| ⚪ 白色 | 🔵 蓝色 | 400人 | 90% | 兵力翻倍，属性-10% |
| 🔵 蓝色 | 🔵 蓝色 | 400人 | 100% | 完美匹配 |
| 🔵 蓝色 | 🟣 紫色 | 600人 | 90% | 兵力+50%，属性-10% |
| 🟣 紫色 | 🟣 紫色 | 600人 | 100% | 完美匹配 |
| 🟣 紫色 | 🟠 橙色 | 800人 | 90% | 兵力+33%，属性-10% |
| 🟠 橙色 | 🟠 橙色 | 800人 | 100% | 完美匹配 |
| 🟠 橙色 | 🟡 金色 | 999人 | 90% | 兵力+25%，属性-10% |
| 🟡 金色 | 🟡 金色 | 999人 | 100% | 完美匹配（AI专属） |

**优势**：
- ✅ 初期玩家可以提前使用高级部队
- ✅ 低稀有度武将也有价值
- ✅ 部队卡资源利用率高
- ✅ 成长曲线更平滑
- ✅ 平衡性更好（-10%惩罚适中）

## 📊 数学验证

### 战斗力计算公式

```javascript
部队基础战斗力 = 武将武力 × 10 × 部队人数 / 100

稀有度匹配修正 = {
  完美匹配: 1.0,    // 同级部队卡
  高一级: 0.90,     // 高一级部队卡，属性-10%
}

部队最终战斗力 = 部队基础战斗力 
                × 稀有度匹配修正
                × (1 + 武将勇气/20) 
                × (1 + (奋战值-50)/100)
```

### 收益分析

| 武将稀有度 | 部队卡 | 兵力提升 | 属性惩罚 | 总战斗力变化 | 结论 |
|-----------|--------|---------|---------|-------------|------|
| 白色 | 白→蓝 | +100% | -10% | **+80%** | ✅ 大幅提升 |
| 蓝色 | 蓝→紫 | +50% | -10% | **+35%** | ✅ 显著提升 |
| 紫色 | 紫→橙 | +33% | -10% | **+20%** | ✅ 明显提升 |
| 橙色 | 橙→金 | +25% | -10% | **+12.5%** | ✅ 稳定提升 |

**计算示例**：
```
白色武将 + 蓝色部队卡：
兵力提升：400 / 200 = 2.0（+100%）
属性修正：0.90（-10%）
总战斗力：2.0 × 0.90 = 1.8（+80%）
```

**结论**：所有情况下，兵力提升带来的收益都大于-10%属性惩罚！

## 🎯 策略指南

### 初期策略（1-2级官职）

**资源情况**：
- 武将：主要是白色和蓝色
- 部队卡：白色为主，少量蓝色

**推荐配置**：
1. 白色武将 + 蓝色部队卡（如果有）→ +80%战斗力
2. 蓝色武将 + 蓝色部队卡（完美匹配）
3. 白色武将 + 白色部队卡（资源不足时）

**优先级**：
- 优先给主力武将配备蓝色部队卡
- 次要武将使用白色部队卡

**推荐配置**：
1. 紫色武将 + 紫色部队卡（完美匹配）
2. 蓝色武将 + 紫色部队卡（如果有多余）→ +35%战斗力
3. 蓝色武将 + 蓝色部队卡（标准配置）

**优先级**：
- 主力武将追求完美匹配
- 次要武将可以使用高一级部队卡

### 后期策略（5级以上官职）

**资源情况**：

2. 紫色武将 + 橙色部队卡（如果有多余）→ +20%战斗力
3. 紫色武将 + 紫色部队卡（标准配置）

**优先级**：
- 核心武将追求完美匹配
- 辅助武将灵活配置

## 💡 设计亮点

### 1. 平衡性更好

**-10%惩罚的优势**：
- 白→蓝：+80%战斗力（原-5%时为+90%）
- 蓝→紫：+35%战斗力（原-5%时为+42.5%）
- 紫→橙：+20%战斗力（原-5%时为+26.4%）
- 橙→金：+12.5%战斗力（原-5%时为+18.8%）

**平衡性分析**：
- 初期提升仍然很大（+80%）
- 中后期提升更合理（+20%~+35%）
- 完美匹配的价值更高
- 鼓励玩家培养高稀有度武将

### 2. 策略深度增加

**选择1：完美匹配**
- 优势：部队属性100%，发挥最大战斗力
- 劣势：兵力较少
- 适合：追求稳定输出，资源充足

**选择2：高一级匹配**
- 优势：兵力大幅提升
- 劣势：部队属性-10%
- 适合：追求兵力优势，资源紧张

**策略考量**：
- 初期：优先选择高一级部队卡（+80%收益巨大）
- 中期：根据战斗需求灵活选择
- 后期：核心武将追求完美匹配

### 3. 完美匹配价值提升

**原设计（-5%惩罚）**：
- 高一级匹配收益太大
- 完美匹配价值不明显
- 玩家倾向于全部使用高一级

**新设计（-10%惩罚）**：
- 高一级匹配收益合理
- 完美匹配价值明显
- 玩家需要权衡选择

## 📝 实现清单

### 数据结构

```javascript
// 部队配置
const troopConfig = {
  characterId: 'char_san_1101',
  characterRarity: 'common',      // 白色武将
  troopCardId: 'troop_card_001',
  troopCardRarity: 'rare',        // 蓝色部队卡
  
  // 匹配度
  matchType: 'higher',            // 'perfect' or 'higher'
  attributeModifier: 0.90,        // 属性修正（高一级-10%）
  
  // 兵力
  maxSize: 400,
  currentSize: 400,
};
```

### 战斗力计算

```javascript
function calculateTroopPower(character, troopCard, morale) {
  // 基础战斗力
  const basePower = character.combat * 10 * troopCard.currentSize / 100;
  
  // 稀有度匹配修正
  const matchModifier = getMatchModifier(character.rarity, troopCard.rarity);
  
  // 勇气加成
  const courageBonus = 1 + character.courage / 20;
  
  // 奋战值加成
  const moraleBonus = 1 + (morale - 50) / 100;
  
  // 最终战斗力
  return basePower * matchModifier * courageBonus * moraleBonus;
}

function getMatchModifier(characterRarity, troopCardRarity) {
  const rarityLevel = {
    'common': 1,
    'rare': 2,
    'epic': 3,
    'legendary': 4,
    'core': 5,
  };
  
  const charLevel = rarityLevel[characterRarity];
  const cardLevel = rarityLevel[troopCardRarity];
  
  if (charLevel === cardLevel) {
    return 1.0;  // 完美匹配
  } else if (cardLevel === charLevel + 1) {
    return 0.90;  // 高一级，-10%
  } else {
    return 0;  // 不允许（相差超过1级）
  }
}
```

- 允许武将携带高一级部队卡
- 高一级部队卡有-10%属性惩罚（原为-5%）
- 兵力提升仍然大于属性惩罚

**主要优势**：
- ✅ 初期玩家战斗力大幅提升（+80%）
- ✅ 中后期提升更合理（+20%~+35%）
- ✅ 完美匹配价值更明显
- ✅ 策略选择更有深度
- ✅ 平衡性更好

**数学验证**：
- 所有情况下总战斗力都提升
- 白色→蓝色：+80%
- 蓝色→紫色：+35%
- 紫色→橙色：+20%
- 橙色→金色：+12.5%

**平衡性分析**：
- -10%惩罚比-5%更合理
- 完美匹配的价值更高
- 鼓励玩家培养高稀有度武将
- 策略选择更有意义
