# 阵型系统

## 📋 系统概述

阵型系统是战斗中的核心策略要素，当部队数≥3时可选择阵型，获得不同的属性加成和特殊效果。

### 核心理念

- ✅ **经典阵型** - 参考三国志系列经典阵型
- ✅ **属性加成** - 不同阵型提供不同加成
- ✅ **集团攻击** - 整队编制成阵型，同时行动
- ✅ **策略深度** - 根据敌人选择合适阵型

---

## 🎯 阵型解锁条件

| 部队数 | 可用阵型 | 说明 |
|--------|---------|------|
| 1-2支 | 无阵型 | 散兵作战 |
| 3支 | 基础阵型 | 锋矢、鹤翼、鱼鳞 |
| 4支 | 进阶阵型 | 方圆、偃月 |
| 5支 | 高级阵型 | 八卦、长蛇 |

### 1. 锋矢阵 (Arrow Formation) 🔺

**解锁条件**：3支部队

**阵型布局**（7×7棋盘）：
```
. . . . . . .
. . . A . . .
. . B . C . .
. . . . . . .
. . . . . . .
. . . . . . .
. . . . . . .

A = 前锋（1支）
B = 左翼（1支）
C = 右翼（1支）
```

**属性加成**：
- 攻击力：+2.0
- 移动力：+1
- 突破力：+30%

**特殊效果**：
- **锋矢突击** - 集团攻击时，对单个目标造成150%伤害
- **破阵** - 对防御阵型额外+20%伤害

**适用场景**：
- ✅ 进攻作战
- ✅ 快速突破
- ✅ 单点击破
- ❌ 不适合防守

**历史典故**：
锋矢阵如箭头般锐利，集中兵力于一点，适合突破敌阵。

## 🎮 集团攻击系统

### 核心机制

**集团攻击**：将整个阵型作为一个整体，同时对敌方发起攻击。

### 操作方式

1. **选择阵型** - 战斗开始前选择阵型
2. **进入战场** - 按阵型布局部署部队
3. **集团移动** - 选择"集团移动"，整个阵型一起移动
4. **集团攻击** - 选择"集团攻击"，所有部队同时攻击

### 集团攻击效果

```javascript
// 集团攻击伤害计算
const groupAttackDamage = {
  // 基础伤害 = 所有部队攻击力之和
  baseDamage: troop1.attack + troop2.attack + troop3.attack + ...,
  
  // 阵型加成
  formationBonus: formation.attackBonus,
  
  // 集团加成（多支部队协同）
  groupBonus: troopCount * 0.2,  // 每支部队+20%
  
  // 最终伤害
  finalDamage: baseDamage * (1 + formationBonus + groupBonus),
};
```

### 集团攻击示例

**锋矢阵集团攻击**（3支部队）：
```
伤害 = (部队1攻击 + 部队2攻击 + 部队3攻击) × 1.5 × 1.6
     = 总攻击力 × 2.4

说明：
- 1.5 = 锋矢突击效果（150%）
- 1.6 = 集团加成（3支部队 × 20% = 60%）
```

**八卦阵集团攻击**（5支部队）：
```
伤害 = (5支部队总攻击) × 1.5 × 2.0
     = 总攻击力 × 3.0

说明：
- 1.5 = 八卦阵计谋加成（150%）
- 2.0 = 集团加成（5支部队 × 20% = 100%）
```

### 集团攻击优势

1. **高伤害** - 多支部队同时攻击，伤害爆炸
2. **快速清场** - 一次性消灭大量敌军
3. **减少疲劳** - 不需要逐个操作每支部队
4. **战略性强** - 需要选择合适的时机和目标

### 集团攻击限制

1. **冷却时间** - 使用后需要2-3回合才能再次使用
2. **士气消耗** - 每次集团攻击消耗1.0士气
3. **阵型要求** - 必须保持阵型完整
4. **范围限制** - 只能攻击阵型前方的敌人

## 📊 阵型数据结构

```javascript
const formation = {
  // 基础信息
  id: 'formation_0001',
  name: '锋矢阵',
  type: 'arrow',
  rarity: 'common',
  
  // 解锁条件
  requirements: {
    minTroops: 3,  // 最少3支部队
    maxTroops: 3,  // 最多3支部队
  },
  
  // 阵型布局（相对位置）
  layout: [
    { position: [3, 1], role: 'vanguard' },  // 前锋
    { position: [2, 2], role: 'leftWing' },  // 左翼
    { position: [4, 2], role: 'rightWing' }, // 右翼
  ],
  
  // 属性加成
  bonuses: {
    attack: 2.0,
    movement: 1,
    breakthrough: 0.3,
  },
  
  // 特殊效果
  specialEffects: [
    {
      name: '锋矢突击',
      description: '集团攻击时，对单个目标造成150%伤害',
      trigger: 'groupAttack',
      effect: { damageMultiplier: 1.5 },
    },
    {
      name: '破阵',
      description: '对防御阵型额外+20%伤害',
      trigger: 'attackDefensiveFormation',
      effect: { damageBonus: 0.2 },
    },
  ],
  
  // 集团攻击配置
  groupAttack: {
    cooldown: 2,        // 冷却2回合
    moraleCost: 1.0,    // 消耗1.0士气
    range: 2,           // 攻击范围2格
    aoeSize: 3,         // 影响3×3区域
  },
  
  // 适用场景
  suitableFor: ['进攻', '突破', '单点击破'],
  notSuitableFor: ['防守'],
  
  // 历史典故
  history: '锋矢阵如箭头般锐利，集中兵力于一点，适合突破敌阵。',
};
```

## 💡 战术应用

### 1. 进攻战术

**推荐阵型**：锋矢阵、长蛇阵

**战术流程**：
```
1. 选择锋矢阵
2. 快速移动到敌阵前
3. 使用集团攻击突破
4. 击溃敌军主力
```

### 2. 防守战术

**推荐阵型**：鱼鳞阵、方圆阵

**战术流程**：
```
1. 选择鱼鳞阵
2. 占据有利地形
3. 等待敌人进攻
4. 反击时使用集团攻击
```

### 3. 包围战术

**推荐阵型**：鹤翼阵、偃月阵

**战术流程**：
```
1. 选择鹤翼阵
2. 两翼包抄敌军
3. 形成包围圈
4. 集团攻击歼灭
```

### 4. 谋略战术

**推荐阵型**：八卦阵

**战术流程**：
```
1. 选择八卦阵（需高智力）
2. 使用计谋削弱敌军
3. 变换阵型迷惑敌人
4. 集团攻击收割
```

## 📝 总结

### 阵型系统特点

1. ✅ **经典还原** - 参考三国志经典阵型
2. ✅ **策略深度** - 7种阵型，各有特色
3. ✅ **集团攻击** - 创新玩法，减少疲劳
4. ✅ **数值平衡** - 加成范围0.0-10.0
5. ✅ **克制关系** - 阵型间有克制

### 集团攻击优势

1. ✅ **高伤害输出** - 多支部队协同
2. ✅ **快速清场** - 一次性消灭大量敌军
3. ✅ **减少操作** - 不需要逐个操作
4. ✅ **战略性强** - 需要选择时机

### 解锁进度

| 阶段 | 部队数 | 可用阵型 | 战斗力 |
|------|-------|---------|--------|
| 新手 | 1-2 | 无 | 基础 |
| 初期 | 3 | 锋矢/鹤翼/鱼鳞 | 中等 |
| 中期 | 4 | +方圆/偃月 | 较强 |
| 后期 | 5 | +八卦/长蛇 | 最强 |

### 与其他系统关联

- **角色系统** - 角色属性影响阵型效果
- **部队系统** - 部队数量决定可用阵型
- **战斗系统** - 阵型影响战斗结果
- **士气系统** - 集团攻击消耗士气

这个阵型系统既有经典三国志的味道，又有创新的集团攻击玩法，非常适合你的游戏设计！💪
