## 文档概述

本文档定义游戏前端（game）的完整UI设计，包括移动端和PC端的布局、交互、导航等。

**核心理念**：
- 移动端优先 - 竖屏布局，拇指友好
- 响应式设计 - 适配移动/平板/PC
- 简洁高效 - 减少页面跳转，提升操作效率
- 沉浸体验 - 最大化内容区域，最小化UI干扰

## 1. 移动端UI设计

### 1.1 整体布局

**布局结构**：顶部状态栏 + 主内容区 + 底部Tab导航

```
┌─────────────────────────────────────────────┐
│ [主城-洛阳] 🎖️120 🤝50 💰50 🌾1200 [⚙️]    │ ← 顶部固定（56px）
├─────────────────────────────────────────────┤
│                                             │
│                                             │
│                                             │
│            主内容区域                        │
│            (根据Tab切换)                     │
│            (自适应高度)                      │
│                                             │
│                                             │
│                                             │
├─────────────────────────────────────────────┤
│   📋编组   ⚔️军团   🏰主城   🗺️地图         │ ← 底部固定（64px）
└─────────────────────────────────────────────┘
```


### 1.2 顶部状态栏

**高度**：56px（h-14）  
**背景色**：深色系（琥珀色/棕色），符合三国主题  
**固定定位**：`fixed top-0`，始终在顶部  
**层级**：`z-50`，确保在其他内容之上

**布局结构**：

```
┌─────────────────────────────────────────────┐
│ [标题]  🎖️120 🤝50 💰50 🌾1200  [⚙️]       │
│  ↑       ↑    ↑   ↑   ↑          ↑         │
│  左侧   声望 贡献 银两 粮草      右侧        │
└─────────────────────────────────────────────┘
```

**左侧：当前页面标题**
- 动态显示当前Tab的标题
- 字体：text-lg font-bold
- 颜色：text-white

**标题映射表**：

| 当前Tab | 标题显示 | 说明 |
|---------|----------|------|
| 编组 | "编组配置" | 固定标题 |
| 势力 | "势力管理" | 固定标题 |
| 主城 | "主城 - 洛阳" | 显示城市名称 |
| 地图 | "世界地图" | 固定标题 |

**中间：四大资源**
- 🎖️ **声望**（Reputation）：荣誉累积，只增不减，用于官职晋升
- 🤝 **贡献**（Contribution）：可消费货币，用于兑换橙色/紫色卡牌
- 💰 **银两**（Silver）：通用货币，日常购买
- 🌾 **粮草**（Food）：战斗资源，出征和恢复兵力

**资源显示格式**：
```jsx
<div className="flex items-center space-x-1 bg-black/20 rounded-full px-2 py-1">
  <span className="text-yellow-300">💰</span>
  <span className="text-white text-sm font-medium">50</span>
</div>
```

**资源不足提示**：
- 当资源 < 阈值时，背景变为红色并闪烁
- 示例：银两 < 10 → `bg-red-500/30 animate-pulse`

**右侧：设置按钮**
- 图标：⚙️
- 点击后弹出个人中心侧边栏
- 字体：text-xl


**官职自动装备动画方案**：

当玩家获得官职时，触发以下动画流程：

**方案1：卡牌飞入动画（推荐）**
```
1. 全屏半透明遮罩淡入（0.3s）
2. 官职卡从屏幕中央放大出现（0.5s）
   - 带有金色光效和粒子特效
   - 卡牌旋转360度
3. 显示官职信息（1s）
   - 官职名称
   - 官职等级
   - 属性加成
4. 卡牌缩小并飞向官职槽位（0.5s）
   - 带有拖尾特效
   - 槽位发光提示
5. 卡牌嵌入槽位，槽位闪光（0.3s）
6. 遮罩淡出，显示"官职已装备"提示（0.3s）

总时长：约3秒
```

**方案2：简化版动画**
```
1. 官职槽位高亮闪烁（0.5s）
2. 官职卡从上方滑入槽位（0.5s）
3. 槽位发光，显示"官职已装备"（0.5s）

总时长：约1.5秒
```

**方案3：无动画版（快速）**
```
1. 直接装备官职
2. Toast提示："官职【军候】已自动装备"

总时长：即时
```

**推荐使用方案1**，理由：
- 官职获得是重要时刻，值得华丽动画
- 增强玩家成就感
- 符合卡牌游戏的视觉语言
- 可以在设置中提供"跳过动画"选项

#### 编组数据面板（已实装）

**位置**：将领配置页面下方，竖屏时在军营区域上方

**显示内容**：
```
📊 编组数据
⚔️ 组合战力    77        💥 暴击率     18.1%
🌾 出征消耗    31 粮     🎲 闪避率     7.1%
⏱️ 恢复时间    满编      🏅 将领排名   尚未实装
```

**恢复时间显示**：
- 满编 → 灰色 `满编`
- 恢复中 → 黄色 `余X分钟`（换行）`（X粮）`
- 粮草不足 → 红色 `⚠️粮草不足`
- 将领有2张部队卡时，恢复时间取较长的，粮草取总和

**恢复时间逻辑**（自动恢复机制）：
- 恢复速率：10兵/分钟（现实时间）
- 粮草消耗：`ceil(损失兵力 / 10)`
- 恢复时间 = 粮草消耗（分钟），数值一致便于估算
- 后端在每次读取 profile 时自动结算：根据 `last_troops_lost_at` 计算已恢复兵力，扣粮草，更新 `current_troops`

**卡牌特效系统**（通用机制）：
- 效果卡类型：称号/成就/宝物（`EFFECT_CARD_TYPES`）
- 装备/卸下/更换任何卡牌时：清零该角色所有部队卡 bonus → 重新应用所有已装效果卡加成
- 防叠加：每次操作都从0开始重新计算，不累加
- 属性加成（`attributeBonus`）：实时计算不存数据库，翠绿色（`text-emerald-400`）高亮显示

**官职槽**（已实装）：
- 缩略显示：名字 + 稀有度 + 资源加成 + 兵种加成 + 特权
- 点击查看完整 PositionCard（共享组件，只读）
- 无卸下/更换按钮（官职由系统分配）

- 每个城市的具体数值（人口、商业、农业、军事、文化）
- 驻守部队显示和操作
- 点击城市可跳转到主城Tab查看详情

**势力资源**：
- 银两储备（30%势力保留）
- 粮草储备（30%势力保留）
- 当天预估发放给当前玩家的银两和粮草数值

**资源兑换**：
- 功能：玩家可以用银两购买粮草，或用粮草兑换银两
- 兑换机制：与势力资源储备池进行兑换（非虚空兑换）
- 兑换限制：如果储备池某项资源为0，则无法兑换该资源
- 基础兑换比例：
  - 银两 → 粮草：1:5（1银两 = 5粮草）
  - 粮草 → 银两：5:1（5粮草 = 1银两）
- 动态比例机制：
  - 储备池资源越少（稀缺），价格越高（兑换比例越低）
  - 储备池资源越多（充足），价格越低（兑换比例越高）
  - 动态调整范围：基础比例的 50% - 200%
  - 示例：
    - 粮草充足（储备 > 80%）：1银两 = 10粮草（200%）
    - 粮草正常（储备 40%-80%）：1银两 = 5粮草（100%）
    - 粮草稀缺（储备 < 40%）：1银两 = 2.5粮草（50%）

**官职列表**：
- 查看所有官职的当前玩家
- 官职等级和权限说明

#### 🏰 主城（Tab3）
**定位**：直接跳转到当前驻地主城

**功能说明**：

**城防 / 驻地编组**（详见 [13-2-CITY_DEFENSE_SYSTEM.md](../10-core-system/13-2-CITY_DEFENSE_SYSTEM.md)）：

**驻地定义**：
- 驻地是玩家存放备用部队卡的城市
- 每个玩家只能有1个驻地

**驻地选择规则**：
- ✅ 可选驻地类型：大城（city_major）、中城（city_medium）
- ❌ 不可选：小城（city_small）、关隘（gate）、要塞（fort）
- 新玩家默认驻地为势力首都（大城）

**长官玩家特殊规则**：
- 驻地自动设置为担任长官的城市
- 可以在本城市免费即时替换部队卡
- 长官被罢免后，部队卡自动转移到最近的己方大城/中城

**普通玩家规则**：
- 可选择任意己方大城或中城作为驻地
- 更换驻地需要24小时冷却和1000银两
- 更换时所有部队卡自动转移到新驻地

**主城功能**：
- 查看和管理仓库中的部队卡
- 调换上阵部队卡（即时，消耗粮草=兵力/20）
- 配置驻守部队（守城卡池A和B，每套2将领+4部队）
- 如果是长官，可以操作特殊建筑（如果有权限）

**部队卡三种状态**：

| 状态 | 说明 | 数量限制 | 位置 |
|------|------|---------|------|
| 上阵 | 跟随玩家战斗 | 最多4张 | 玩家身上 |
| 驻军 | 守城卡池配置 | 2套（A和B），每套2将领+4部队 | 守城卡池 |
| 仓库 | 存放备用 | 无限制 | 驻地城市 |

**调动机制**：
- 同城替换：即时（0分钟），粮草=兵力/20
- 异地替换：需要时间（3-10分钟），粮草=兵力/20
- 调动时间根据距离计算（每10瓦片+1分钟，最多10分钟）

- ✅ 可手动关闭
- ✅ 大地图视图下左下角显示最小化入口按钮

**最小化入口主标识（优先级）** — `CommPanel` 收起态左下角按钮的 **emoji + 主文案** 按下列顺序择一显示（角标数字为该通道的未读/条数提示，实现见组件 props）：

```javascript
// 通信浮层自动隐藏逻辑
let hideTimer = null;

function onNewMessage(message) {
  // 显示浮层
  setCommVisible(true);
  
  // 清除之前的定时器
  if (hideTimer) {
    clearTimeout(hideTimer);
  }
  
  // 如果不是用户主动打开，10秒后自动隐藏
  if (!isUserOpened) {
    hideTimer = setTimeout(() => {
      setCommVisible(false);
    }, 10000);
  }
}

function onUserOpenComm() {
  // 用户主动打开，不自动隐藏
  setIsUserOpened(true);
  setCommVisible(true);
  
  // 清除自动隐藏定时器
  if (hideTimer) {
    clearTimeout(hideTimer);
  }
}

function onUserCloseComm() {
  // 用户主动关闭
  setIsUserOpened(false);
  setCommVisible(false);
}
```

#### 8.2.3 字体加载

**@font-face 声明**：
```css
@font-face {
  font-family: 'JYHPHS';
  src: url('/fonts/JYHPHS.woff2') format('woff2');
  font-weight: normal;
  font-style: normal;
  font-display: swap;
}
```

**加载策略**：
- `font-display: swap` - 确保文字在字体加载前使用备用字体显示，避免闪烁
- 字体文件使用 woff2 格式，体积小（约2-3MB）、加载快
- 字体文件路径使用绝对路径 `/fonts/JYHPHS.woff2`，确保在所有页面都能正确加载

### 8.7 性能注意事项

**⚠️ 禁止在可滚动浮层中使用 `backdrop-blur`**：
- `backdrop-blur` 每帧都要对背后内容做高斯模糊计算，GPU 开销极大
- 当浮层下方有大图（如地图背景）且浮层内容可滚动时，会导致明显卡顿
- **替代方案**：使用高不透明度纯色背景（如 `bg-gray-900/95`），视觉效果接近但性能好很多
- **已踩坑组件**：CommPanel（战报/传书/聊天浮层）— 移除 `backdrop-blur-sm` 后滚动流畅
- **未来注意**：传书系统、聊天系统实装时同样避免使用 `backdrop-blur`

**公告栏/排行榜等静态浮层**：
- 不可滚动的小面积浮层可以保留 `backdrop-blur-sm`（如公告栏、排行榜折叠状态）
- 这些浮层内容固定、不涉及滚动，性能影响可忽略

### 9.1 编组Tab详细设计（已实装 v2026-03-26）

**核心定位**：战前准备和配置，暗黑破坏神风格装备界面

**布局架构**：
- 竖屏：子Tab切换（[玩家名] / 将领1 / 将领2）→ 中央角色卡 + 左右装备槽 → 编组数据面板 → 军营
- 横屏（≥768px）：2×2 四象限布局（左上=玩家 | 右上=将领1 | 左下=军营 | 右下=将领2）

**子组件清单**：

| 组件 | 功能 | 说明 |
|------|------|------|
| `EquipmentLayout` | 中央角色卡+左右装备槽 | 竖屏主布局 |
| `LandscapeQuadrant` | 横屏单象限 | 角色卡+槽位+数据面板 |
| `EquipSlot` | 单个装备槽位 | 空槽/已装备/不可用三态 |
| `LineupStatsPanel` | 编组数据面板 | 战力/暴击/闪避/消耗/恢复 |
| `BackpackSection` | 军营（背包） | 按类型分组，稀有度圆点计数 |
| `CardDrawer` | 底部选择抽屉 | 可装备卡牌列表 |
| `CardDetailOverlay` | 卡牌详情浮层 | 装备/卸下/更换操作 |
| `GeneralNotRecruited` | 将领未招募提示 | 显示可招募将领列表 |
| `TroopCardCropped` | 部队卡裁剪版 | 槽位内缩略显示 |

**槽位配置**：

玩家（6槽）：
```
左侧：⚔️部队 / 👑官职（只读）/ 🛡️装备卡（未实装）
右侧：🎖️称号 / 🏆成就（未实装）/ 💎宝物（未实装）
```

将领（6槽）：
```
左侧：⚔️部队1 / ⚔️部队2 / 🛡️装备卡（未实装）
右侧：🎖️称号 / 🏆成就（未实装）/ 💎宝物（未实装）
```

**交互流程**：
- 点击空槽 → 底部抽屉弹出可装备卡牌列表
- 点击已装备槽 → 详情浮层（100%卡牌 + 更换/卸下按钮）
- 点击官职槽 → 只读详情（PositionCard）
- 点击将领角色卡 → 详情浮层（可卸下将领）
- 将领未招募 → 显示可招募将领列表，点击招募

**数据转换函数**：
- `toTroopCardData()` — 后端卡牌实例 → TroopCard props
- `toCharacterCardData()` — 后端卡牌实例 → CharacterCard props
- `toTitleCardData()` — 后端卡牌实例 → TitleAchievementCard props
- `toEquipmentCardData()` — 后端卡牌实例 → EquipmentCard props
