# 部队图标资源目录

**目录用途**: 存放部队卡牌图标

---

## 📁 文件命名规范

**格式**: `{troop_id}.png`

**示例**:
```
troop_san_1001.png  // S1赛季，通用部队，第1个（民兵）
troop_san_1006.png  // S1赛季，通用部队，第6个（轻骑兵）
troop_san_1011.png  // S1赛季，通用部队，第11个（弓箭手）
```

---

## 📐 图标规格

| 项目 | 规格 |
|------|------|
| 推荐尺寸 | 400 × 400 px |
| 最小尺寸 | 256 × 256 px |
| 最大尺寸 | 512 × 512 px |
| 文件格式 | PNG（支持透明背景）|
| 目标大小 | 50-150KB |
