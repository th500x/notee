# 部队编组系统组件

## 概述
M2验证模块的核心组件，实现武将+部队卡组合机制。

## 组件结构

### TroopFormationSystem.jsx
主要的部队编组系统组件，包含：

- **编组管理**: 添加/删除编组，最多支持6个编组
- **武将选择**: 从武将库中选择武将，支持搜索和势力筛选
- **部队选择**: 从部队库中选择部队，支持搜索和兵种筛选
- **战力计算**: 实时计算组合战力（基础属性 + 10%组合加成）
- **一键编组**: 自动为所有编组分配可用的武将和部队
- **临时图标**: 使用emoji作为占位符图标

## 功能特性

### 战力计算公式
```
基础战力 = 武将属性（攻击+防御+智力）+ 部队属性（攻击+防御+生命）
组合战力 = 基础战力 × 1.1（10%组合加成）
总战力 = 所有编组的组合战力之和
```

### 临时占位符图标
- 👤 武将
- 🛡️ 部队
- ⚔️ 编组
- 💪 战力
- ➕ 添加
- ❌ 移除
- 🎯 自动编组

## 使用方法

1. 点击"选择武将"按钮选择武将
2. 点击"选择部队"按钮选择部队
3. 查看实时计算的组合战力
4. 使用"添加编组"创建更多编组
5. 使用"一键编组"自动分配

## 技术实现

- 使用React Hooks管理状态
- 集成现有的useCharacters和useTroops hooks
- 模态框选择器界面
- 响应式网格布局
- 实时数据计算和更新
