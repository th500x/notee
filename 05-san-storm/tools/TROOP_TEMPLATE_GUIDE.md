# 部队卡模板使用指南

## 📋 模板文件

**文件名**：`troop-template.csv`

**用途**：设计和管理所有部队卡的属性数据

## 🆔 ID命名规则

### 格式

```
troop_{系列代码}_{赛季}{势力}{编号}
```

### 系列代码

| 系列 | 代码 | 说明 |
|------|------|------|
| 三国 | san | 三国系列部队 |

### 势力编号（1位）

| 势力 | 编号 | 说明 |
|------|------|------|
| 通用 | 0 | 所有势力可用 |

### 编号规则（2位）

- 每个势力最多99个部队卡（01-99）
- 建议按兵种和稀有度分组

### 重要说明

- ✅ **稀有度不在ID中体现**，使用独立的 `rarity` 字段
- ✅ **兵种类型不在ID中体现**，使用独立的 `troopType` 字段
- ✅ **ID规则与角色ID规则保持一致**（`char_san_1102`）
- ✅ **便于按赛季和势力管理部队卡**
- ✅ **通用部队（势力编号0）所有势力都可以使用**

## 📊 字段说明

### 基础信息

| 字段 | 说明 | 示例 | 必填 |
|------|------|------|------|
| ID | 部队卡唯一标识 | troop_infantry_0001 | ✅ |
| 名称 | 部队卡名称 | 民兵 | ✅ |
| 稀有度 | common/rare/epic/legendary/core | common | ✅ |
| 兵种类型 | infantry/cavalry/archer | infantry | ✅ |

### 战斗属性

| 字段 | 说明 | 范围 | 必填 |
|------|------|------|------|
| 射程 | 攻击距离（格数） | 1-4 | ✅ |
| 攻击 | 攻击力 | 60-120 | ✅ |
| 防御 | 防御力 | 50-120 | ✅ |
| 速度 | 行动顺序 | 1-10 | ✅ |
| 移速 | 移动距离（格数） | 2-4 | ✅ |
| 最大兵力 | 根据稀有度 | 200/400/600/800/999 | ✅ |

### 地形适应性

| 字段 | 说明 | 范围 | 必填 |
|------|------|------|------|
| 平原适应 | 平原地形修正 | 0.5-1.2 | ✅ |
| 丘陵适应 | 丘陵地形修正 | 0.5-1.2 | ✅ |
| 森林适应 | 森林地形修正 | 0.5-1.2 | ✅ |
| 水域适应 | 水域地形修正 | 0.5-1.0 | ✅ |

### 克制关系

| 字段 | 说明 | 可选值 | 必填 |
|------|------|--------|------|
| 克制兵种 | 克制哪个兵种 | infantry/cavalry/archer | ✅ |
| 被克兵种 | 被哪个兵种克制 | infantry/cavalry/archer | ✅ |

### 技能（可选）

| 字段 | 说明 | 示例 | 必填 |
|------|------|------|------|
| 技能ID | 技能唯一标识 | skill_cavalry_charge | ❌ |
| 技能名称 | 技能显示名称 | 骑兵冲锋 | ❌ |
| 技能描述 | 技能效果描述 | 首回合攻击+30% | ❌ |
| 技能效果 | 技能效果代码 | firstRoundAttack:0.3 | ❌ |

### 其他

| 字段 | 说明 | 示例 | 必填 |
|------|------|------|------|
| 说明 | 备注信息 | 白色步兵 | ❌ |

## 🔧 技能效果代码格式

**格式**：`属性名:数值`

**多个效果**：用分号`;`分隔

**示例**：
```
firstRoundAttack:0.3                    // 首回合攻击+30%
defense:0.2                             // 防御+20%
defense:0.3;counterAttack:0.5           // 防御+30%且反击+50%
movement:1;attack:0.2                   // 移速+1且攻击+20%
attack:0.4;ignoreTerrain:true           // 攻击+40%且无视地形
ignoreDef:0.3                           // 无视30%防御
aoeRange:3                              // 攻击范围3×3
lowHpAttack:1.0                         // 生命低于30%时攻击+100%
```

## 🎨 设计建议

### 1. 稀有度递进

- 白色：基础属性，无技能
- 蓝色：属性提升，无技能
- 紫色：属性提升，1个技能
- 橙色：属性大幅提升，1个强力技能
- 金色：属性最高，1个超强技能

### 2. 兵种平衡

**步兵**：
- 优势：防御高，适应地形
- 劣势：速度慢，移速慢
- 定位：防守、持久战

**骑兵**：
- 优势：攻击高，速度快，移速快
- 劣势：防御低，地形限制
- 定位：进攻、机动、突袭

**弓兵**：
- 优势：远程攻击，高地优势
- 劣势：防御最低，近战弱
- 定位：远程输出、支援

### 3. 技能设计原则

- 白色/蓝色：无技能（保持简单）
- 紫色：实用技能（+20-30%）
- 橙色：强力技能（+30-50%或特殊效果）
- 金色：超强技能（+50-100%或多重效果）

### 4. 数值平衡

**攻击 vs 防御**：
- 步兵：防御 > 攻击（防御型）
- 骑兵：攻击 > 防御（进攻型）
- 弓兵：攻击 > 防御（输出型）

**速度 vs 移速**：
- 步兵：速度慢，移速慢
- 骑兵：速度快，移速快
- 弓兵：速度中等，移速慢

## 🚀 使用流程

1. **打开模板**：用Excel/WPS打开 `troop-template.csv`
2. **设计部队**：根据参考数值填写部队属性
3. **保存文件**：保存为CSV UTF-8格式
4. **转换数据**：运行转换工具（未来开发）
5. **导入游戏**：生成的JS文件导入游戏
