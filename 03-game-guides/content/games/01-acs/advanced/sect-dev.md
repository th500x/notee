# 进阶 · 门派发展

> **定位**：山门如何从「能住」长成「能养多个内门 + 稳定产出 + 可渡劫/结丹」。  
> **前置**：基础《玩法与机制》《种子地图》《MOD·建筑》。  
> **原则**：先功能分区与风水正确，再谈美观；门派风水并非越高越好（声望↑袭击↑）。

---

## 0. 发展阶段总览

| 阶段 | 约略目标（普通周目） | 基建重点 |
|---|---|---|
| **奠基（约 1–20 天）** | 不死、有宿舍工坊、有简易聚灵 | 外门通铺、厨房食堂、冷库、基础工位 |
| **成型（约 20–60 天）** | 首个一品/上品结丹、代理起步 | 内门单间、正式法座聚灵、丹房符台、仓库分类 |
| **扩张（金丹～元神）** | 多内门、藏经、五行修炼室 | 产线分离、高阶仓、修炼堂/战斗堂区 |
| **终局设施** | 渡劫场、极限聚灵、主题分区 | 13×13 渡劫区、五行专房、预留空地 |

天数随难度/MOD/操作浮动；用「目标」对齐，不要死磕日历。

## 1. 开荒节奏（衔接到成型）

与基础开荒路标一致，进阶只强调 **空间决策**：

1. **第一天暂停**：小地图标灵土（蓝）、沃土（黄）、巨银杏、灵树、寒晶/火铜矿、水域。  
2. **山门落点**：重要仓与钟楼等可靠中部；聚灵区社区经验常偏 **地图左下**（灵气刷新方向相关，可实测）。  
3. **外门靠边**：宿舍+工坊+食堂，少占核心灵土。  
4. **灵土用途**：少则做交感/灵植；多则可药田+修炼。  
5. **勿一次挖光** 寒晶/火铜；预留精锭与控温。  
6. **围墙**：中后期敌人多飞/跳，房间墙体比外墙更有意义；地图外圈留空可防刷新贴脸（大地图规划党经验）。

详细 1–50 天物资清单仍以高赞开荒帖为辅，本站以「空间+系统」为主。

## 2. 房间种类与规范（必须背熟）

### 2.1 朝向（上北下南，左西右东）

| 房间类型 | 门朝向 | 备注 |
|---|---|---|
| 卧房、祖师殿 | **坐北朝南**（门向下） | 内门床属性贴功法 |
| 工坊、炼丹、炼宝 | **坐西朝东**（门向右） | |
| 厨房 | **坐东朝西**（门向左） | |
| 仓库（无风水建筑） | 自由 | 不算风水、可多门 |

- 通向外界的多向门 → **风水外泄**趋凶；可用镇物补救。  
- 大包小：小房间门可灵活，大房间仍要满足类型朝向（社区/Wiki 口径）。  
- 双扇同向并排可视为一扇。

### 2.2 外门 vs 内门住房

| | 外门 | 内门 |
|---|---|---|
| 合住 | 可大通铺（控拥挤） | **必须单间**，混住易情绪崩 |
| 风水 | 统一大吉即可 | 床与功法同属；环境 **生** 功法属性 |
| 温度 | 通铺+季节换衣 | 火铜/寒晶建材需置物台平衡 |

**土生金通铺**（棕石墙地+铁床）温度随季节、少控温，是外门经典方案（BWIKI 风水文）。

### 2.3 功能房五行速记

| 功能 | 相生思路示例 |
|---|---|
| 厨房 | 火生土：土灶 + 火装饰/地板等 |
| 工坊 | 常拆水木 / 火土两套工位，或同房水火地板分区控温 |
| 自带属性建筑 | 炉灶熔炉带火、水井带水——选材按「自带+材料」算 |
| 内门修炼房 | 法座=功法属；周围相生；法座下可压聚灵 |

镇物：鉴定后按条件放 → 大吉+特效；条件错 → 大凶。

### 2.4 门派风水策略（BWIKI 五档）

| 档位 | 大致条件 | 备注 |
|---|---|---|
| 九幽绝地 | ≥90% 建筑大凶 | 控声望/特殊玩法 |
| 逆运之局 | ≥60% 凶/大凶 | |
| 灵秀之地 | 吉凶都不超 60% | 过渡常态 |
| 修行宝地 | ≥60% 吉/大吉 | 常规目标 |
| 仙家洞天 | ≥90% 大吉 | 声望与袭击压力升高 |

室内风水建筑追大吉；室外多数吉即可。  
**声望**：风水档上升常加声望 → 敌人变强。前期可用「大凶山门」等控声望（基础篇已提），进阶期再决定是否冲洞天。

**多门规则（Wiki）**：无风水房视为外界；仅一扇门通外界时以该门判朝向；全内门时取最合适门。

## 3. 分区规划范式

### 3.1 中小型实用分区（推荐回坑）

```
[仓A][仓B] | [工坊带] [食堂厨] | [外门通铺]
           | [药田/农田]        | [娱乐]
[高阶仓]   | [丹房][宝房]       | [内门带]
           | [聚灵/结丹]        | [修炼堂区]
           | [渡劫预留]         | [山门/阵眼]
```

游民经典「左仓、中功能+田、右住、上丹宝」仍好用。

### 3.2 大地图网格党

大地图约 192²：先定中轴与道路奇偶，再切 **20×20** 功能块（含墙与路宽）。中轴放「全门唯一」建筑（护山大阵、山门等）；外围农田；丹宝靠高阶仓；最外留空防刷怪。对称好看但 **不是必须**——正确风水优先。

### 3.3 道路经验

- 干道 2～3 格，支路统一奇偶，后期改房不崩。  
- 先定路网再填风水组合，比先盖后拆省心（TapTap 建筑长文方法论）。

## 4. 聚灵与爆灵（门派效率引擎）

> 机制主源：BWIKI《地块灵气浓度》（与贴吧长文同源）。结丹章只讲「要用高灵气」；**怎么堆**写在这里。

### 4.0 灵气怎么「流动」（心智模型）

- 灵气像水：往 **聚灵更深** 的地方汇。聚灵物在约 **5 天** 内给范围内格子加聚灵。  
- 开局有 **灵脉**（约 197、不衰减）；**切勿把灵脉直接塞进阵心**——一旦该格聚灵 >197，灵脉价值崩掉，反致全图灵气下滑。靠近即可。  
- 面板「5+」≈ 约 2000+；极限结丹要远高于此。  
- **≈2500** 是衰减加速临界：再往上堆会明显变难（Wiki）。

### 4.1 稳态聚灵阵

目标：多件聚灵物范围叠在 **同一中心格**（法座/蒲团；**炼法坛**可作强力中心，非风水建筑）。  

| 圈层 | 思路 | 范围示例 |
|---|---|---|
| 最外 | 范围大 | 灵木、龙鳞、玄麟、火羽等（范围 4） |
| 中圈 | 范围 3 | 玄牝珠等 |
| 内圈 | 范围小 | 星髓、玉髓等 |
| 中心 | 法座 / 炼法坛 | 炼法坛约 600 聚灵（需灵晶），早中期极强 |

几何：按 **几何距离**（对角用勾股），不是随便数圈。Wiki 经典菱形分层图：外 4 → 中 3 → 内 2 → 座。  
**同圈聚灵值尽量齐**：外圈比内圈「更深」会像破桶漏灵（「灵气黑洞」）。  
外圈可用灵木；**内圈与角色功法相生** 优先照顾五行。  
建好后 **等数日** 让中心饱和，再谈爆灵。煞性灵植至少离阵缘 **15 格**；灵性灵植扰动大，宜导不宜当稳态主力。

### 4.2 爆灵（手动灵气爆发）

**原理**：移动/放下聚灵物会触发方形 **聚灵重置**（范围约 `(2n−1)²`，n=聚灵范围）→ 该区聚灵清零、灵气向周围扩散 → 被阵心「更深的池」吸住。重置后约 **5 天** 恢复。  
**硬规则**：不要动法座/阵心格上的聚灵；**必须有时间差**（暂停连点会被当成同一次重置）。

| 地图尺寸 | 灵气刷新间隔（游戏时间，Wiki） |
|---|---|
| 大 | 约每 1 小时 |
| 中 | 约每 0.5 小时 |
| 小 | 约每 15 分钟 |

**基础四角灵木法**：阵外四角放灵木，结丹前按序 1→2→3→4 **至少每小时移一件**（顺/逆时针皆可）；移完放回原位，勿收回仓库。随手乱移约半效果。  
**升级八点法**：沿阵周置物台路线 1…8 逐步挪放，等每次灵气变动后再下一步。  

| 阶段体感（Wiki 实测口径） | 约略灵气 |
|---|---|
| 开局耐心基础爆 | 2000+ |
| 灵木阵极限约 | ~3000 |
| 中后期够超品 | ~4000 |
| 材料极品逼近 | ~5000（再抬操作性极差） |

信息 MOD（显示格子灵气）强烈建议结丹/爆灵期开。

### 4.3 与产线的关系

- 聚灵抬区域灵气，利农田药田（可靠聚灵区铺田）。  
- 结丹/入定/部分突破共用高灵气点——规划峰值位，避免产线与结丹互抢乱动阵心。  
- 改岩石地形偶发毁灵脉 → 短暂枯竭；有备用聚灵物即可。

## 5. 产业与仓储

### 5.1 外门产线

| 产线 | 要点 |
|---|---|
| 木石加工 | 铁制工具换代；勿把代理建材全加工掉 |
| 农耕 | 沃土优先；20×20 围房+香炉可四季；棉麦药草结构随阶段调 |
| 狩猎 | 开局清危险兽；尸体可肥田 |
| 冶炼 | 寒晶/火铜分炉；控温与精锭配额 |
| 烹饪制药 | 灶台大吉防火；岐黄外门伤够用即可 |

### 5.2 内门产线

| 产线 | 房间 | 要点 |
|---|---|---|
| 炼丹 | 朝东、炉属性与丹五行相生 | 大吉房；毁丹/圣品策略服务结丹与寄托 |
| 炼宝 | 朝东 | 法宝材料与词条服务战斗/渡劫 |
| 画符 | 符纸与本命符节奏 | 符修核心；可快速画符 MOD 减负 |
| 藏经 | 录入降参悟耗 | 与流派养成章衔接 |

### 5.3 仓库规范

- **无风水**：多门、近产线。  
- **分类**：修仙道具细分；镇物单独；火属性物未入房前严防自燃。  
- **阶位**：低阶仓近日常工位；6–12 阶仓贴丹宝房。  
- **重要置物台**：木雨剑、高阶衣等单独架，防狗啃/乱堆。

## 6. 堂口与区域划分

游戏内可划 **修炼堂、战斗堂** 等区域：

| 堂 | 用途 |
|---|---|
| 修炼堂 | 结丹/学技能/吃参悟丹的加成环境；悟性心境相关操作 |
| 战斗堂 | 渡劫与战斗向加成 |

内门卧室、聚灵房、堂区三者靠近，减少跑图浪费。

## 8. 发展规划检查清单

**每天/每周扫一眼**

- [ ] 外门是否有人闲置或过劳情绪崩  
- [ ] 内门房间是否大吉、温度是否极端  
- [ ] 聚灵中心灵气是否仍在爬升  
- [ ] 仓库是否爆仓导致停工  
- [ ] 声望是否突然拔高导致袭击碾压  

**每阶段验收**

- [ ] 奠基：全员有床有饭有工具  
- [ ] 成型：稳定结丹点 + 至少一个代理  
- [ ] 扩张：五行房与藏经运转  
- [ ] 终局：渡劫场实测打过至少一次工具人/小号劫
