# 基础 · MOD

> **口径**：Steam PC 一代。优先用游戏内 **模组商店 / 万界天宫** 管理订阅与排序。  
> **原则**：MOD 是体验放大器，不是通关必选项；改列表前 **备份存档**。  
> **排除**：修改器、解锁全资源、恶性刷取类——本站基础层不推荐。

## 1. 创意工坊怎么用（最少步骤）

1. Steam 库打开游戏 → 主菜单进入 **模组商店** 或 **万界天宫**（官方/社区均建议由此管理，比纯浏览器工坊好排依赖）。  
2. 订阅物品后回到游戏，在模组列表中 **启用**，注意上下游依赖与排序。  
3. 扩展类 MOD（加机制、加物品）取消订阅可能导致旧档缺物/报错；轮回者/蓝图类相对温和，但仍建议备份。  
4. 网页工坊偶发「物品已移除 / 仅作者可见 / 显示不兼容」——**以客户端能否订阅并加载为准**。  
5. 天道异动、大型内容补丁后，旧蓝图可能要微调房间尺寸（见建筑节留言区经验）。

### 1.1 三类内容别混

| 类型 | 从哪来 | 典型用途 |
|---|---|---|
| 模组商店扩展 | 工坊「机制/功能」MOD | 同福客栈、自动历练、UI 信息等 |
| 万界天宫内容 | 内容编辑器上传的轮回者/物品/蓝图 | 自制角色、门派蓝图 |
| 本地 Mods 文件夹 | 安装目录 `Mods/` | 开发/非工坊包（进阶） |

排序经验（社区合集常见说法）：同类冲突时，**模组商店扩展往往放在万界内容之前**；具体以作者说明为准。

## 2. 轮回者生态

### 2.1 原版轮回者（无 MOD 也能玩）

开局选人界面点 **轮回者**，输入姓名（及性别/种族等匹配信息）生成 **固定属性** 角色。  
优点：开荒稳定、社区攻略可复现；带星轮回者在玄牝重生等流程中属性更不易被洗烂（开荒长文常见提醒）。

官方/社区整理的完整名单篇幅长，英文 Wiki 指向玩家整理的 Reincarnator 表格；中文侧多看 TapTap/贴吧「轮回者推荐」帖。本站 **具体配队表** 放 advanced，基础层只给「怎么用 + 常见开荒班底」。

### 2.2 常见开荒班底（交叉：TapTap 超详细版 + BWIKI 新手向）

下列为 **高复现** 组合思路，不是唯一神队；同名角色在不同数据帖里可能有二创/整活版本，启用前在游戏内核对五维与词条。

| 角色 | 常见定位 | 备注 |
|---|---|---|
| 陆夫人 | 火功法匹配、丹器向内门工具人 / 阳修过渡 | 多篇开荒文核心 |
| 狗叔 | 高巧匠/雅艺外门苦力 | 常与陆夫人同框出现 |
| 千小茜 | 魅力/处世向；土属性功法匹配；外交/结丹节奏位 | 用于破心防、代理、门派互动 |
| 虎/熊/狼妖 | 体修候补 | 看化形天劫天数，过早勿硬上 |
| 申申如也等 | 命运之子等特殊词条向 | BWIKI 新手流程常见 |

开局经历常见选法：妖修白嫖功法 + 「一心救人」加弟子栏等——以你当次可选经历列表为准。

### 2.3 推荐 MOD：同福客栈（招募向）

| 项 | 内容 |
|---|---|
| 名称 | **同福客栈**（作者常见署名 **tefeink**） |
| 作用 | 约第 7 天解锁地点「同福客栈」，可邀请太古系列/随机轮回者；后续版本支持招募 **已订阅的万界天宫轮回者**；可打听秘闻（含后期古修相关概率） |
| 额外价值 | 社区称可突破常规招募人数限制（以 MOD 说明为准） |
| 查找 | 游戏内模组商店搜「同福客栈」；勿与无关同名作品混淆 |

> 网页工坊链接稳定性一般，本文不硬编码易失效的 id；以游戏内搜索结果为准。

### 2.4 订阅他人的轮回者

路径概念：主菜单 → 万界天宫 → 轮回者相关页浏览/订阅他人作品 → 开局按姓名启用；若装了同福客栈，也可在客栈的「模组轮回者」类选项中招募（每名通常限一次）。

## 3. 自建轮回者并上传 Steam（官方能力，可做）

**结论：可以。** 无需写代码，走万界天宫内容编辑器即可。

### 3.1 步骤（综合英文 Wiki + Steam 讨论指南）

1. 主菜单 → **万界天宫** → **内容编辑器** → **创建轮回者**（及配套「经历」编辑）。  
2. 用自定义 **经历** 拉五维与技能倾向（滑条/星兴趣）；把经历标成 **特殊**，降低污染普通 NPC 生成池（社区强烈建议）。  
3. 为轮回者配置童年/成年/特殊经历、词条（点 + 号添加）。  
4. 起名、写描述，勾选左侧保存。  
5. 勾选要发布的若干轮回者 → **上传** 至 Steam 创意工坊。  
6. 订阅自己的物品并启用 → 新开局输入姓名即可调用。

### 3.2 限制与注意

- 轮回者通常 **不能改名**（创建时定名）。  
- 五维往往通过「经历加成」叠到底子上，不是每个字段无限手填。  
- 一次上传可打包多名，便于开荒套件。  
- 上传即受 Steam 创意工坊规范约束；违规可能被移除（仅作者可见）。  
- 更复杂机制（新系统、改代码）超出内容编辑器，需传统 MOD 开发（`Mods/` + 程序集），不在基础层展开。

### 3.3 和同福客栈的配合

自建并订阅 → 同福客栈「模组轮回者」中可招募 → 适合把「攻略站推荐配队」做成可一键获取的工坊包（本站若自制，另开版本说明）。

## 4. 建筑 / 蓝图 MOD

建筑向在工坊里大量是 **蓝图（建造预设）**，不是改规则，而是「抄作业式铺房」。常与 **快速建造** 类辅助搭配。

### 4.1 推荐方向（按需求订阅，勿一次全开）

| 方向 | 示例关键词（工坊内搜索） | 说明 |
|---|---|---|
| 整派功能 | **全功能门派建筑群 V3.0**（社区流传 id 约 `2650737718`） | 外门/内门住房、工位、法座较全；坐标拼接；(0,0) 多为山门主殿；天道异动后外门房间尺寸或需手改 |
| 开荒风水 | **初期大吉蓝图套装** | 降低前期风水翻车 |
| 分区模板 | 内门对称房、五行小别墅、神修房、真仙难度全天气大吉套等 | 按阶段取用 |
| 辅助 | **快速建造** / 部分修改器自带建造加速 | 只为铺蓝图省时间；选「仅建造辅助」即可 |

### 4.2 使用方法（蓝图通用）

1. 订阅蓝图 +（可选）快速建造。  
2. 按作者给出的坐标系拼接（常见以山门为原点）。  
3. 用观星台检查是否仍大吉；天气/地形/天道异动词条可能导致偏差。  
4. 新手目标：**能睡、能吃、有工位、有法座/聚灵位**；美化包后置。

### 4.3 自建蓝图

万界天宫内容编辑器同样支持蓝图类内容（与轮回者同属「无代码内容」）。把自己调通的宿舍/工坊/聚灵外壳传工坊，便于多周目复用。

## 5. 功法类 MOD

> 功法 MOD 最容易「一订阅就变另一个游戏」。基础层原则：**先玩熟原版符修/七杀/两仪**，再按需加 **单本精心魔改**；巨型内容包与「一键全功法」默认后置。

### 5.1 怎么分类（订阅前先对号）

| 类型 | 在改什么 | 基础层态度 |
|---|---|---|
| **传功减负** | 不新增天花板功法，只改善「录入/互传/学习」体验 | 可优先考虑 |
| **单本魔改功法** | 加 1～少数几本完整功法（技能、丹方、秘闻获取） | 回坑第二周目起推荐尝试 |
| **主题内容包** | 一批功法 + 地点/道具/轮回者（遮天、诛仙、鸿蒙系等） | 当「新周目主题服」用；勿与多包混装 |
| **规则向解锁** | 全部功法获取、功法属性共存、高阶随意互传等 | 改变收集与平衡，写攻略须标注；萌新不优先 |

### 5.2 传功减负（贴近原版）

| 关键词（工坊内搜） | 说明 |
|---|---|
| **藏经阁**（功能向） | 社区安利常提：把可学内容沉淀在门派侧，减轻「人死法断、代际参悟爆炸」；仍受原版进阶/冲突等限制的说法较常见——以该 MOD 说明为准 |
| 一键录入藏经阁 / 快速画符 | 属 QoL，见下节；不新增功法强度 |

### 5.3 单本魔改功法（精选向，可交叉到工坊描述）

下列在创意工坊有明确作者说明、具备独立获取途径与强度自评，适合「想多一条路线、又不想装巨型包」时选用。**名称以游戏内搜索为准**，网页 id 易失效故不硬编码。

| 功法名（搜） | 属性印象 | 作者说明摘要（归纳） | 适合谁 |
|---|---|---|---|
| **六道凌天法** | 木 | 元神前强、后期刻意回落；自带丹方与突破消耗；宣称终局强度约对齐「北斗七杀真诀」量级；机缘门槛 + 炼丹峰历练等秘闻获取 | 喜欢有起有落的叙事向练法 |
| **九转狱火焚天诀** | 火 | 偏术法；结丹起就频繁见劫、后期准备窗极短；意图补「法修弱于器修」；强度自评接近北斗/六道一线 | 想玩术法、能接受高压天劫节奏 |
| **北斗七杀真诀**（及相关） | 常被上述 MOD 当作强度标尺提及 | 工坊内请核对是否为独立条目或合集依赖 | 作对照，勿与原版「七杀剑诀」混名 |

订阅建议：

1. **一次只开一本新功法**，打完再换，方便判断平衡与 BUG。  
2. 读清：五维需求、获取天数/地点、是否改天劫节奏、老档能否触发。  
3. 与「全部功法获取」类同时开，容易失去收集乐趣且难以排查冲突。

### 5.4 主题内容包（周目主题，非默认推荐）

工坊/玩家整理里常见名称（举例，非完整榜）：**太古 / 鸿蒙** 系列、遮天世界、修仙正史、诛仙传、神通现世、太虚无极剑诀、三清秘传、无极魔典 等。  
共性：往往一次塞入多功法 + 新地点/道具/轮回者。  

| 何时用 | 何时别用 |
|---|---|
| 原版内容玩腻，想开「主题周目」 | 第一周目学机制 |
| 只开 **一个** 主题包 + 必要 QoL | 多包叠装（排序地狱、数值膨胀） |
| 接受存档绑定该包 | 还要对照本站「原版流派」攻略写笔记 |

### 5.5 规则向功法 MOD（慎用）

| 关键词 | 风险 |
|---|---|
| 全部功法获取 / 开局送功法海 | 跳过探索与门派互动 |
| 功法共存 / 属性不再互斥 | 改变修炼与技能规划前提 |
| 高阶功法随意传授 | 削弱代际与藏经成本 |

本站若引用带此类 MOD 的视频/速通，会在条目上标 **「非原版规则」**。

### 5.6 功法 MOD 最小实践清单

1. 周目 A：纯原版功法（对照本站「主流派」章）。  
2. 周目 B：原版 + **一本** 单本魔改（如六道或狱火）。  
3. 周目 C：再考虑单一主题包。  
4. 永远备份；出问题用「只留嫌疑功法 MOD」二分法排查。

## 6. 其他常被提到的 QoL（可选，分级）

下列在安利文中反复出现；**本站按「干扰原版规则程度」分级**，请按需勾选。

| 分级 | 例子 | 建议 |
|---|---|---|
| 信息向 | 「更多信息」类（看聚灵细节） | 学习机制时推荐 |
| 减负向 | 自动历练、快速画符、一键录入藏经阁、贸易数量 | 百小时后减重复劳动可考虑 |
| 规则向 | 大衍神算结果限定、开局海量材料经历 | 改变获取节奏，速通/养老向；写攻略时需标注「有 MOD」 |
| 不推荐（基础层） | 数值修改器、全解锁、恶性刷取 | 破坏进度感，且易毁档 |

「窝囊流 / 正道速通」视频里常见 MOD 搭配仅作参考，且部分内容混有贰/存档梗——引用时注意平台标签。

## 7. 回坑最小 MOD 清单（建议）

若你只想「少踩坑、不多改规则」：

1. （可选）同福客栈——方便招轮回者与秘闻。  
2. （可选）初期大吉或全功能蓝图之一——先把房子摆正。  
3. （可选）信息向 MOD——看懂聚灵。  
4. （可选，第二周目）**一本** 单本魔改功法——见 §5。  
5. 其余一律周目稳定后再加。

纯原版 + 官方轮回者完全可玩；MOD 不是门槛。

## 8. 风险清单

- 订阅爆炸导致排序冲突、读档失败 → 禁用二分法排查。  
- 取消扩展 MOD 后旧档物品缺失。  
- 蓝图大吉在异动词条下失效。  
- 多功法包叠装导致数值与秘闻冲突。  
- 网页搜到的「整合包下载站」风险高，优先 Steam 订阅。  
- 标题含「修仙模拟器」的无关游戏/手游 MOD 教程勿用。
