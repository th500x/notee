## 1. 这游戏在玩什么

你以近似「天道」的视角，经营一座从零起步的修仙门派：

1. **生存与基建**（主要靠外门）：砍树、种田、狩猎、建造、控温、仓储。  
2. **修炼与突破**（主要靠内门）：筑基入门 → 结丹 / 金丹 → 元神等，配合聚灵、风水、功法匹配。  
3. **世界互动**：历练、驻扎、进场景拿物资、门派外交、异闻剧情、天劫与袭击。  
4. **长期目标**：门派做强、弟子飞升，或推进异闻/结局线（有关键天数节点，细分章再写时间轴）。

高自由度意味着「没有唯一主线任务栏」——所以基础层最重要的是：**内外门分工、风水、聚灵、功法匹配** 四条主轴。

## 2. 外门与内门（全游戏主轴）

| | 外门弟子 | 内门弟子 |
|---|---|---|
| 角色 | 打工人 | 修仙者 |
| 日常 | 砍树、种田、建造、狩猎、做饭、加工 | 修炼、画符、历练/驻扎、战斗、炼丹炼器等 |
| 晋升 | 筑基值攒满（勤学苦练等）可升内门 | 晋升时选定功法，一般不可随意更换（特殊手段如玄牝重生等除外） |
| 住房 | 可多人合住大宿舍 | 宜单独房间；与外门混住易导致内门情绪变差 |

**回坑心法**：前期至少保证「有人干活、有人修炼」。全员冲内门会导致基建崩盘；全员打工又会错过修炼窗口。

开局可用筑基丹直接送一人入内门，也可用勤学苦练 + 熊胆/蛇胆等把筑基值堆到门槛再晋升（社区常见筑基阈值约 **25000**，以你客户端面板为准）。

## 3. 人物面板：五维、技能、词条

### 3.1 五维（与五行对应）

| 五维 | 对应五行 | 常见作用（摘要） |
|---|---|---|
| 神识 | 金 | 视野、细致工作相关 |
| 根骨 | 木 | 身体强度、耐温、体力活相关 |
| 魅力 | 水 | 好感、破心防、部分外交/代理主持 |
| 悟性 | 火 | 学习/参悟速度；不少地图事件有悟性门槛 |
| 机缘 | 土 | 幸运、历练掉宝、奇遇类门槛 |

另有 **潜力**：受五维与年龄影响；晋升内门时会固化为内门相关上限（如炼精化气上限一类），故内门候补要挑，外门苦力对五维要求低得多。

### 3.2 技能三排（外门视角）

- **粗工杂役**：巧匠（制作速度/品质，极重要）、金石、农耕、版筑等。  
- **妙术巧技**：雅艺（配合巧匠抬品质）、处世、烹饪、岐黄等。  
- **修行资质**：气感（内门灵气相关，候补尽量高）、战斗、斗法、丹器等——外门难靠训练猛涨，选人时就要看。

技能上的「星」表示兴趣：学得快、干活心情更好。

### 3.3 词条 / 身世

有好有坏。回坑优先避开明显折磨体验的负面（如严重丑陋影响他人心情、短命等）。正面如命运之子、龙血者等，社区开荒文常点名，细则见轮回者/词条细分章。

### 3.4 种族（人 / 妖）

妖族开局可白嫖部分功法/经历收益，但有 **化形天劫** 时间压力：天劫过早（如几十天内）极难救；拖到中后期（社区常提百日级以后）更从容。妖族走 **体修** 渡劫往往比硬抗仙修雷劫稳。虎/熊/狼等常作体修候补；龟类移速慢，开荒期慎选主力。

## 4. 五行与风水

建立门派后建造 **观星台**，才能看清地块五行、建筑吉凶与单位影响圈。风水不是「好看」，而是直接影响心情、效率，并汇总为 **门派风水**（极端时影响运势与关键检定）。

### 4.1 五行生克（背这张表）

- **相生（吉向）**：木→火→土→金→水→木  
- **相克（凶向）**：木↔土、火↔金、土↔水、金↔木、水↔火（按经典五行）

修炼时：环境 **生** 功法属性 → 事半功倍；环境 **克** 功法属性 → 变慢甚至突破翻车、情绪持续变差。

### 4.2 风水建筑 vs 装饰

| 类型 | 特征 | 作用 |
|---|---|---|
| 风水（功能）建筑 | tip 含「风水建筑」：床、灶、工作台、多数门派建筑等 | 有吉凶评价；要环境「生」它 |
| 装饰建筑 | 灯笼、鼎、墙、地板等 | 本身无吉凶，用来改周围五行，把功能建筑「生」到大吉 |

部分建筑 **自带属性**（如炉灶/熔炉带火、水井带水），选材时要按「自带 + 材料」一起算，不能只看锭的颜色。

### 4.3 房间大吉三要素

1. **屋内风水建筑本身尽量大吉**（地板、邻墙、装饰相生）。  
2. **拥挤度**：太挤或太空都难大吉；用装饰/镇物微调。  
3. **门朝向**（社区与 BWIKI 一致口径）：  
   - 卧房 / 祖师殿：**坐北朝南**（门朝南/下）  
   - 工坊 / 炼丹炼宝：**坐西朝东**（门朝东/右）  
   - 厨房：**坐东朝西**（门朝西/左）  
   - 多方向开门通向外界 → **风水外泄**趋凶；无风水建筑的纯仓库可不算风水，门可更自由。

**镇物**：满足放置条件可「一键」拉大吉并带附加效果；条件不满足会变凶——务必先鉴定再放。

### 4.4 门派风水档位（摘要）

从极凶到极吉大致为：九幽绝地 → 逆运之局 → 灵秀之地 → 修行宝地 → 仙家洞天（以大吉/凶建筑占比划分）。  
门派风水上升常伴随 **声望** 变化，声望高会拉高来袭强度——前期不必盲目追求「满图大吉」。社区有「大凶山门」等控声望/虐垃圾袭击的玩法，属进阶技巧。

### 4.5 内门房间与法座

- 床、法座属性宜与弟子 **功法属性一致**；周围环境宜 **生** 其属性。  
- **法座** 在门派声望达标后解锁（社区常提约 500 声望，以你局内解锁为准），舒适度高于蒲团，是正经修炼中心。  
- 炼丹/炼宝：丹炉属性与丹药/材料五行也有相生讲究（如水丹偏金炉等社区经验），基础层先记住「炼房也要大吉 + 朝向正确」。

天气（暴雨、沙尘暴等）会暂时压风水评价，属正常现象。

## 5. 灵气、聚灵阵与爆灵

修炼速度与结丹品质高度依赖弟子所在格子的 **灵气浓度**（面板常显示到 5+，实际可更高）。聚灵体系是本游戏最核心的「人造优势」。

### 5.1 聚灵物

地图/物品带 **聚灵值** 与 **聚灵范围**。在范围内，离聚灵物越近，对该格贡献越大；多件聚灵物效果可叠加。

常见前期材料：

| 资源 | 作用摘要 |
|---|---|
| 灵木（砍灵树） | 泛用聚灵物；缺料时可劈成灵木料但聚灵变差 |
| 巨银杏 | 前期强力聚灵中心候选（高聚灵 + 较大范围） |
| 灵土 | 高肥沃 + 高聚灵；宜药田/灵植/修炼区规划 |
| 星髓、玄牝珠、朱果、赭黄精等 | 中后期按范围分层摆阵 |

### 5.2 聚灵阵（稳态）

目标：让尽可能多的聚灵物，其有效范围都盖住 **同一个中心格**（法座/蒲团），且中心叠满。

摆法原则（机制文 + 社区一致）：

1. **范围大的放外圈，范围小的贴中心**。  
2. 聚灵范围按 **几何距离/边长** 理解，不是随便「数格子圈数」；斜向要用距离概念，硬摆正方形容易在对角「真空」。  
3. 中心可用法座，法座下还可压聚灵物；蒲团多为过渡。  
4. 建好后需 **等待数日** 让中心灵气抬升/饱和，再谈进阶操作。

### 5.3 爆灵（进阶，基础层只建立概念）

对聚灵物做「挪动 / 拾取放下 / 井字棋等交互」会触发 **重新聚灵**，格子内积攒的灵气向四周扩散，可使中心格 **短暂突破** 原稳态上限。  
要点：

- 先稳态聚满，再爆。  
- **不要乱动最中心** 那件关键聚灵物。  
- 可按节奏轮换外围点以维持「爆发态」（操作繁琐，属细分章图解内容）。

> 基础层结论：回坑第一周先摆稳「能用的聚灵/简易爆灵」；极限圆形阵、超级爆灵轮转留给 advanced。

### 5.4 修炼速度乘区（面板右上角一类提示）

多种系数 **相乘**——任一极差（多个减号）都会把速度打穿。常见项：

| 系数 | 如何变好（摘要） |
|---|---|
| 功法匹配 | 五维贴合功法需求；丹药/技能/交感等可抬 |
| 舒适度 | 更好衣服、更好法座（灵晶炼法坛等后期更高） |
| 时节 | 四季五行不同，影响匹配 |
| 师徒 | 同功法师父加成更好 |
| 五行匹配 | 法座环境属性正确且纯度高 |
| 情绪 | 吃穿住行娱乐、待遇、房间舒适 |
| 心境 | 见下节 |
| 灵气 | 聚灵阵/爆灵拉高所在格灵气 |

### 5.5 心境

修炼会掉心境；过低（社区常提 &lt;30）进入崩溃，恢复变慢。修炼期尽量维持舒适区间（社区常提尽量 &gt;50）。  
**调心** 可缓慢回心境、消执念，但有上限，一般不会靠调心 alone 拉到极高。心境基础值可在详细属性查看，并可用符咒/技能抬高。心境「越高越好」与「过高掉得快」在社区有争议——基础层建议：**保证不崩溃、结丹前拉到舒适**，极致堆叠留给细分。

## 6. 参悟、技能与藏经阁

- 功法技能与内门基础属性多靠 **参悟** 点。  
- 学技能会加 **道行**；道行越高，后续技能越贵。  
- 结丹前优先级（社区常见）：抬灵气/气感/心境/历练效率/关键神通，少点战力虚华。  
- **藏经阁** 可学已录入的外功法技能；收录量提升可降低参悟消耗（有上限）。相生属性功法互学更省。  
- 金丹期以上可收徒；师父亲传可大幅减免参悟消耗（亲传弟子额外优惠）。  
- 参悟来源：修炼/调心/练功、录入功法秘籍、后期代理点信仰、道统相关丹药等。

## 7. 历练、驻扎与进地图

| 行为 | 目的 | 注意 |
|---|---|---|
| 历练 | 周期产出资源（如炼丹峰的灵植/灵根向材料） | 高级资源常要求功法五行匹配 + 高机缘；门派属地灵根历练可能被拦 |
| 驻扎 | 主要是为了 **进入** 该地点地图 | 驻扎掉落本身往往一般 |
| 进入地图 | 拿场景唯一/刷新道具、观摩建筑、对话长老 | 进属地地图通常要通行权；历练/驻扎本身不一定要 |

效率小技巧（社区常见）：历练归来点分放四边并附娱乐；佩戴神视/神行类符加快解锁周边地点；蜀山线刷解锁玉泉洞等关键点。

进场景后耗时 **不推进** 门派主世界时间（社区长期共识，便于「进图搜刮」）。

## 9. 地图资源优先级（开荒眼）

| 资源 | 为什么重要 |
|---|---|
| 灵土 | 肥沃 + 聚灵；决定药田/交感区位置 |
| 巨银杏 / 灵树 | 前期聚灵核心 |
| 沃土 | 高效农田 |
| 寒晶矿 / 火铜矿 | 控温、精锭、特殊玩法；勿一次挖光炼光 |
| 货箱 / 残骸 | 布料等；靠近妖兽的慎开（易惊醒） |
| 水域浅滩 | 可铺地板再建；莲藕应急粮 |

规划经验（非唯一）：重要仓库与核心设施偏地图中部；聚灵区有人偏好地图 **左下**（与灵气刷新方向有关的社区经验）；农田/药田可靠聚灵区吃灵气红利。围墙拦不住多数中后期敌人，房间墙体更有意义。

## 10. 装备与生活小规则

- 道具格 + 符咒格有上限；符咒同时生效数量有限（社区常提最多开 3 张，以客户端为准）。  
- **冷暖自知**：按季节自动换衣，减少中暑/冻伤。  
- 温度：寒晶/火铜建材会改变室温，需置物台等平衡，否则冻伤中暑。  
- 尸体可作肥料（药田聚灵相关玩法）；耐药性叠高后同药失效——勿无脑灌药。

---

## 11. 新人 / 回坑常见翻车

1. 开局选极寒等高压图，生存压垮修炼。  
2. 全员内门或全员不筑基。  
3. 忽视风水朝向与相生，内门情绪崩、效率差。  
4. 不建聚灵，干坐半年。  
5. 门派风水拉太高，袭击强度跟不上战力。  
6. 把 EA/2019 老攻略当现行唯一解；或混用手游/贰攻略。
