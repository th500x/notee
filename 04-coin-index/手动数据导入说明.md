# 手动数据导入说明

## 📋 数据录入流程

### 1. 编辑CSV模板文件
文件位置：`coin-index/data-import-template.csv`

### 2. 数据格式说明

| 字段名 | 数据类型 | 取值范围 | 说明 |
|--------|----------|----------|------|
| 周ID | 文本 | 2025-W50, 2026-W01等 | 不要修改，用于匹配现有数据 |
| 恐惧&贪婪指数 | 数字 | 0-100 | 整数，0=极度恐惧，100=极度贪婪 |
| 梅耶倍数 | 数字 | 0.5-3.0 | 小数，通常1.0-2.4范围 |
| Ahr999指标 | 数字 | 0.1-2.0 | 小数，≤0.45抄底，≤1.2定投 |
| BTC四年指数 | 数字 | 0.1-2.0 | 小数，≤0.6低估，≤1.0合理 |

**注意：个人评级将根据上述4个指标自动计算生成**

### 3. 示例数据
```csv
周ID,恐惧&贪婪指数,梅耶倍数,Ahr999指标,BTC四年指数
2026-W01,45,1.46,0.95,0.72
2026-W02,65,1.58,1.12,0.88
```

### 4. 执行导入
在 `coin-index` 目录下运行：
```bash
node scripts/importManualData.js
```

## 🎯 指标含义参考

### 恐惧&贪婪指数 (0-100)
- 0-24: 极度恐惧 😨
- 25-44: 恐惧 😟
- 45-55: 中性 😐
- 56-74: 贪婪 😊
- 75-100: 极度贪婪 🤑

### 梅耶倍数
- <1.0: 低估区域 💚
- 1.0-2.4: 正常区域 💛
- >2.4: 高估区域 ❤️

### Ahr999指标
- ≤0.45: 抄底区间 💚
- 0.45-1.2: 定投区间 💛
- >1.2: 观望区间 ❤️

### BTC四年指数
- ≤0.3: 极度低估 💚
- 0.3-0.6: 低估 💚
- 0.6-1.0: 合理 💛
- 1.0-1.5: 高估 🧡
- >1.5: 极度高估 ❤️

### 个人评级 (自动生成 1-5★)
**基于加权算法自动计算：**
- 恐惧&贪婪指数权重：25%
- 梅耶倍数权重：25%
- Ahr999指标权重：25%
- BTC四年指数权重：25%

**评级标准：**
- 5★: 强烈推荐 🌟 (多个指标处于最佳买入区间)
- 4★: 推荐 ⭐ (大部分指标较好)
- 3★: 观望 ⚪ (指标中性)
- 2★: 谨慎 ⚠️ (部分指标偏高)
- 1★: 避免 ❌ (多个指标处于高估区间)

## 📝 注意事项

1. **CSV格式要求**：
   - 使用逗号分隔
   - 第一行必须是标题行
   - 不要包含额外的空行

2. **数据验证**：
   - 脚本会自动验证数据类型
   - 无效数据会使用默认值
   - 不存在的周ID会被跳过

3. **备份建议**：
   - 导入前建议备份现有数据文件
   - 可以多次运行导入脚本覆盖数据

4. **文件同步**：
   - 脚本会同时更新 `src/data/weeklyData.json` 和 `public/weeklyData.json`
   - 确保两个文件保持同步

## 🔧 故障排除

### 常见错误
- **CSV文件不存在**：确保 `data-import-template.csv` 文件存在
- **格式错误**：检查CSV格式，确保逗号分隔正确
- **数据类型错误**：确保数字字段填写的是有效数字

### 验证导入结果
导入完成后，可以在浏览器中查看应用，选择对应的周查看数据是否正确更新。
