# 基础 · 种子地图

> **为什么单独成章**：开局地图决定灵土/沃土/巨银杏/矿物的位置与体量，直接左右聚灵、种田、控温与规划难度——和「选功法」一样影响整体体验。  
> **口径**：Steam PC 一代。下列种子名来自社区高互动帖；**请在你客户端实测截图核对**，版本与选项不同可能略有差异。

## 1. 怎么用种子（最少步骤）

1. 新开档 → 进入地图相关设置。  
2. 点地图编辑（界面常见 **铅笔** 图标）。  
3. 在输入框填入种子名（如 `菜狗`、`三界无敌043`）→ 确认。  
4. 需要把「自己的好图」给别人：改成好记的名字 → **导出** 得分享码；别人用 **导入** 粘贴。

天道异动周目：种子往往还 **恒定** 部分开局异动相关布局；选词条时仍要自己点（见 §5）。

---

## 2. 开局选项建议（与种子配套）

社区开荒/种子帖里反复出现的「省心组合」：

| 选项 | 更常见推荐 | 说明 |
|---|---|---|
| 地图大小 | **大** | 资源与后期建筑空间更够 |
| 地形 | **平原** | 资源密度友好，新手少踩极寒/极端图 |
| 古代奇物 | **蕴灵树** | 开荒强相关；也有人嫌后期烦，属口味问题 |
| 奇珍异兽 | **蜚**（可选） | 可换玄牝珠等；不强制 |
| 难度 | 先普通 / 再九劫·真仙 | 极品图 + 九劫是进阶组合 |

> 回坑第一周：优先「大 + 平原 + 蕴灵树」，再挑下面「易于上手 / 经典」种子，不要一上来叠最难天道词条。

## 3. 分类怎么读

| 标签 | 含义（本站） |
|---|---|
| **易于上手** | 灵土/沃土好找或体量够，规划压力相对小，适合重开练手 |
| **经典常青** | 社区反复安利、名字好记、讨论多 |
| **极品资源** | 以「超大灵土 / 中心巨银杏」等著称；仍可能有矿物或风水短板 |
| **天道异动向** | 在天道异动讨论里高频；也可当普通周目种子用（以帖内说明为准） |

同一种子可跨类；下表「主标签」只取最突出的一面。

- **太玄 / 太易**：有帖认为纯负面、萌新可跳过。  
- **地母石碑**：许愿向，相对好控。

- **化妖 / 祭妖**：玩法向，按目标勾选。  
- 具体组合以你当次目标为准，本站不替你锁死。

## 5. 怎么选一张「你的」图（决策）

1. **完全回坑练手** → `洪荒` / `菜狗` / `昆仑山` + 大·平原·蕴灵树。  
2. **想少为灵土发愁** → `孤狼卫月3` 或 `多宝轮回宗`。  
3. **真仙/九劫已会开荒** → `历九劫而登仙19` 或天道向 `三界无敌043`。  
4. **爱外交送礼** → `万仙`（喜好表可对照原帖）。  
5. 选定后：**第一天先暂停**，用小地图找灵土（泛蓝）、沃土（泛黄）、巨银杏与灵树，再定山门与聚灵区——与「玩法机制」章资源节一致。

## 6. 注意与免责

- 种子名必须 **一字不差**（含数字、大小写若有）。  
- 地图大小/地形/奇物选项会改变「好不好用」的主观感受。  
- 移动版 / 贰 的种子帖默认 **不适用** 本站 PC 一代口径。  
- 极品图不等于无脑通关：风水、聚灵、功法仍要自己做。  
- 欢迎你实测后回写「灵土方位截图 + 选项」，我们再升版本修订表。
