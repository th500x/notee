# 终局 · 极品宝物

> **定位**：终局强度的「物」侧——不是罗列全图鉴，而是回答：**什么叫极品、怎么做出来、用在哪条养成链上**。  
> **前置**：进阶《流派养成》《门派发展》；基础《主流派》。  
> **态度**：普通难度不需要神器满仓；九劫/极限才吃满圣品与洗练链。数字以 BWIKI / 高赞测试为准，客户端差异以面板为准。

---

## 0. 极品地图（先分四类）

| 类型 | 终局角色 | 典型终点 |
|---|---|---|
| **圣品丹药 / 毁丹** | 抬灵气上限、心境、分神窗口、耐药管理 | 紫毁丹、造化神丹、长生/九转系 |
| **法宝（含神器）** | 战斗与渡劫输出/回灵 | 12 阶神器、秒回件、天劫之息成品 |
| **符咒（圣品）** | 符修本命、渡劫盾、寄托载体品质 | 真玄甲 / 利剑 / 万化承丹等圣品 |
| **镇物 · 天材地宝** | 房间大吉特效、结丹材料、聚灵与词条 | 鉴定镇物、地母灵液、星髓/寒精、遗蜕 |

寄托件本身也可以是「宝物」（秘宝/木料/法宝位）——件表见《流派顶配》，本章只管 **品质从哪来**。

## 1. 「圣品」到底指什么

社区口语里的「圣品」常混用三种含义，写档时分开：

| 口语 | 实际意思 |
|---|---|
| 圣品丹 | 丹药品阶顶格；效果显著优于普通 |
| 圣品符 | 符咒品阶顶格；本命符强度与寄托贴常用 |
| 圣物材质标签 | 炼器 Wiki：材料带「圣物-攻/灵/快…」等，炼成法宝有对应乘区 |

**幽淬之法**（葵花等功法）：可抬 **丹药 / 原料 / 符纸** 品阶；是圣品产线核心技能之一。同类还有 **道淬** 等。  
注意（Wiki 口径）：

- 先幽淬 **原料** 再炼宝，威力更好；幽淬 **已成法宝** 对实际战力帮助有限（社区/Wiki 一致强调）。  
- 已画好的符 **不能** 靠幽淬再抬；要抬就抬符纸再画。

## 2. 丹药极品链

### 2.1 炼丹质量杠杆

| 杠杆 | 作用 |
|---|---|
| 丹炉五行相生 | 产量可明显抬高（Wiki：相生可至约 2× 量级讨论） |
| 炼丹成功率 / 产量加值 / 速度 | 丹师技能与本命符（万化承丹真符+伪符） |
| 大吉丹房 | 稳定；故意大凶炉可用于刷 **毁丹** |
| 九转金丹直指 → 太元五符云箓 | 前中期丹师 → 极限产量符修丹师路径 |

丹师人选：前中期九转性价比高；极限产量走符修万化承丹。

### 2.2 终局常备丹（用途向，非全表）

| 用途 | 代表 | 挂钩 |
|---|---|---|
| 结丹抬上限 | 紫毁丹、地母灵液、赤参/紫芝等 | 《流派养成》结丹内因 |
| 心境窗口 | 清心丹等 | 结丹/突破保无暇档 |
| 分神窗口 | 造化神丹等 | 寄托攒分神；缺丹方时可能用真仙渡劫替代（社区） |
| 渡劫续航 | 真罡丹、灵石/灵晶 | 肉身/法宝渡劫 |
| 寿命/重生 | 长生丹、六道轮回丹、玄牝相关 | 重生寄托流 |
| 耐药管理 | 各类高耐药天材 | 同物多次吃衰减（如地母灵液） |

### 2.3 毁丹（结丹党彩票）

炼丹失败产出 **炼毁的丹药**；**紫色毁丹** 可加最大灵气，是结丹珍贵材料（BWIKI《炼丹》）。  
社区高性价比刷法印象：较低炼丹等级 + **大凶丹炉** + 批量廉价丹（如五灵散）——故意失败刷紫毁。  
风险：占丹炉与时间；注意耐药与仓库分类（防火属性物）。

### 2.4 地母灵液（天材样板）

- 土属；服用大补精元、**永久抬灵气上限**；多次服用扩充效果大幅衰减（耐药约 90%，Wiki）。  
- 获取：天下历练；传说泉眼相关合欢/蜀山玉泉洞等；亦可灵初露蕴养五行灵根等路径。  
- 用途：直接吃抬结丹池；亦作多种神丹材料。

## 3. 法宝极品链

### 3.1 品阶与神器

- 材料与成品皆可谈品阶；**神器 = 12 阶法宝**（社区/游民口径）。  
- 11 阶原料 **炼不出** 12 阶成品——要先把原料品阶做上去。  
- 社区参考关系（游民「秒回」文，需实机核对）：高阶原料灵气与目标品阶相关；8 阶寒精手镯等可用高灵气冲圣物秒回向。

### 3.2 威力从哪来（3DM 测试结论摘要）

1. **先抬原料品阶再炼宝**，优于「低阶炼出再幽淬成品」。  
2. 成品威力 ≈ 原料品阶贡献 × 法宝品阶贡献。  
3. **材料种类** 有天花板：同 12 阶下，**天劫之息** 类可显著高于普通星髓剑等（威力与攻速/回灵/转向多项）。  
4. **渡劫洗练**：法宝渡劫成功可按比例抬威力，**次数无上限**——终局「一直渡一直强」的核心循环之一。

### 3.3 秒回法宝（回灵向）

- 用途：同属性对拼时，高 **回灵速度** 常碾压纯高容量件（游民）。  
- 新手向材料：**寒精锭**、**星髓锭**（社区称目前易出秒回向的主材）。  
  - 寒精：寒山镇等矿向；金/水/木功法常配寒精手镯类。  
  - 星髓：无底洞等；机缘较高（社区常提机缘 >6）的土修探图更稳。  
- 成品推荐印象：星髓针、寒精手镯——亦常作法宝渡劫输出件。

### 3.4 炼宝流程清单

1. 建炼宝台；内门学炼器相关；心境与成功率加成拉满。  
2. 准备高阶原料（幽淬到目标阶）→ 再炼。  
3. 完成后：战斗位装配；需要上限则进入 **渡劫洗练** 循环。  
4. 镇物房大吉可提供额外炼器相关加成（社区提及约百分点级，以实机 tip 为准）。

### 3.5 与寄托 / 渡劫挂钩

| 场景 | 宝物策略 |
|---|---|
| 法宝渡劫 | 高威力针/剑类 + 回灵；防反噬抽干灵气 |
| 肉身渡劫 | 可不带输出法宝；护盾符与秘典优先 |
| 寄托载体 | 高品阶秘宝/法宝位降低分神浪费；契合度养成见顶配章 |
| 两仪多法宝 | 双元神位多，极品件数量需求翻倍 |

## 4. 符咒极品

| 职能 | 圣品方向 | 说明 |
|---|---|---|
| 战斗大哥 | 伪玄甲过渡 → 真玄甲；利剑/灵剑/圣咒等 | 守家与攻坚 |
| 渡劫 | 玄甲为主；法宝渡劫加利剑/灵剑 | 进阶渡劫章 |
| 炼丹 | 万化承丹（伪×多 + 真×1） | 产量极限 |
| 探图 | 神视/神行/分影 | 解锁地图效率 |

符纸先抬品阶再画；寄托流常要求关键符为圣品（B 站寄托流程帖口径）。

## 5. 镇物

- **鉴定** 后按条件摆放 → 房间 **大吉 + 特效**；条件错 → 大凶 + 反向效果。  
- 房外无效（特殊大能镇物可能带聚灵，Wiki/社区例外需看物品 tip）。  
- 终局用法：丹房、炼宝房、修炼堂、内门卧室按功法属性配镇物；凶牙等特殊镇物另有战斗/机制向玩法（独立帖，重玩后再补细表）。

## 7. 周目宝物优先级（可打印）

**成型期（一品结丹前后）**

- [ ] 紫毁/地母等抬上限到位  
- [ ] 战斗法宝至少一件高回灵或高威力  
- [ ] 玄甲类护体符可用  

**扩张期（元神～寄托）**

- [ ] 幽淬产线（葵花工具人或野法）  
- [ ] 圣品关键符到位  
- [ ] 炼宝原料冲 11～12 阶  

**终局限度**

- [ ] 12 阶神器 + 渡劫洗练循环  
- [ ] 天劫之息等顶级材尝试  
- [ ] 遗蜕级聚灵与香火系统运转
